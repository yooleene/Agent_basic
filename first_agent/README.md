# 실습 ⑤ 내 첫 업무 에이전트 만들기

**25분** · 회의록에서 할 일을 뽑는 **에이전트를 직접 만듭니다**

---

## 이 폴더에 있는 것

| 파일 | 무엇 |
|---|---|
| `meeting.txt` | 재료가 되는 회의록 (**수정 금지**) |
| `임직원_명부.json` | 이름·직급·부서 조회표 (**수정 금지**) |
| `요구사항서.txt` | Cursor에 붙여넣을 지시서 |

**코드 파일은 없습니다.** 여러분이 만들 것이기 때문입니다.
그리고 만든 코드도 **읽지 않습니다.** 읽는 것은 실행 화면과 `todo.md` 뿐입니다.

---

## 오늘 만들 것 — 자동화 스크립트가 아니라 에이전트

지금까지 만든 프로그램은 대부분 이런 모양이었습니다.

```
파일 읽기 → AI에게 한 번 물어보기 → 결과 저장 → 끝
```

순서가 코드에 미리 정해져 있습니다. 입력이 뭐든 똑같은 길로 갑니다.

오늘 만드는 것은 다릅니다.

```
계획 → 도구 사용 → 실행 → 검수 →  (통과 못 하면 다시 계획으로)
```

**다음에 무엇을 할지를 코드가 아니라 AI가 매 단계 정합니다.**
그래서 회의록 내용에 따라 도구를 부르는 순서도, 횟수도 달라집니다.

돌아가는 모습은 **브라우저 화면**으로 지켜봅니다.

---

## 진행 순서

### STEP 1 · 재료 확인 (3분)

Cursor에서 **이 폴더를 엽니다.** `meeting.txt` 와 `임직원_명부.json` 을 훑어보세요.

나중에 검수 기준이 되니 미리 세어둡니다.

> 실행 과제로 보이는 것 **____ 건**
> 담당자가 안 정해진 것 **____ 건**
> `박 대리`, `이 책임` 처럼 **직함으로만 적힌 것 ____ 건**

> 💡 `임직원_명부.json` 에서 **"이 책임"을 찾으면 몇 명이 나오나요? ____ 명**
> 이게 나중에 에이전트가 판단해야 할 지점입니다.

### STEP 2 · 요구사항서 넣기 (7분)

`요구사항서.txt` 의 복사 구간을 **통째로** Cursor 채팅에 붙여넣습니다.
Cursor는 **Agent 모드**로 두세요.

> ⚠️ 길다고 일부만 복사하면 에이전트가 안 만들어집니다.
> 특히 **[판단은 AI가 한다]** 항목은 절대 빠뜨리지 마세요.

`agent.py` 가 만들어질 때까지 기다립니다. 코드는 읽지 않아도 됩니다.

### STEP 3 · 실행하고 4단계 지켜보기 (7분)

```
python agent.py
```

**①** 터미널에 회의록 목록이 뜹니다. 번호를 고르거나 그냥 엔터.

```
회의록을 고르세요
  1) meeting.txt        (기본)
번호 입력 [1]: _
```

**②** 브라우저 창이 열리고 카드가 하나씩 쌓입니다. 1초마다 저절로 갱신됩니다.

```
🧭 계획   회의록을 먼저 읽는다
🧰 도구   회의록_읽기()
⚙️ 실행   959자

🧰 도구   담당자_조회("이 책임")
⚙️ 실행   2명 · 이수진 / 이강우
🧭 계획   특정 불가 → 미정으로 처리

🔍 검수   ❌ 실패 — 다음 회의 일정이 섞임
🧭 계획   고쳐서 다시 저장한다
🔍 검수   ✅ 통과
```

**③** 화면이 안 뜨면 **터미널을 보세요.** 같은 내용이 글자로 찍힙니다.

체크하며 보세요.

- [ ] `담당자_조회` 를 **몇 번** 불렀나요? ____ 번
- [ ] `이 책임` 을 조회했을 때 **두 명이 나왔고**, 그 다음에 AI가 뭘 했나요?
- [ ] **빨간 `❌ 검수 실패`** 가 한 번이라도 떴나요? 떴다면 **그 다음 카드가 무엇**이었나요?
- [ ] 몇 단계 만에 끝났나요? ____ 단계

> **빨간 `❌ 검수 실패` 바로 다음에 `🧭 계획` 카드가 나왔다면**,
> 그게 여러분이 오늘 만든 프로그램이 에이전트라는 증거입니다.

### STEP 4 · 결과 검수 (8분)

화면 맨 아래 표를 `meeting.txt` 와 대조합니다. (`todo.md` 파일도 같은 내용입니다)

- [ ] 건수가 STEP 1에 적은 숫자와 비슷한가
- [ ] `박 대리` → **박민호 / 생산기술팀** 으로 바뀌었는가
- [ ] `이 책임` 은 **미정**으로 처리되고 비고에 사유가 적혔는가
- [ ] 담당자를 안 정한 항목(교육장 예약, 수료 기준)이 **미정**인가
- [ ] **비고의 사유가 엉뚱한 항목에 복사되지 않았는가**
- [ ] `다음 주까지`, `가능한 빨리` 가 **임의의 날짜로 바뀌지 않았는가**
- [ ] 다음 회의 일정 · 점심 · 주차장 · 시스템 이관이 **섞이지 않았는가**
- [ ] `meeting.txt` 와 `임직원_명부.json` 원본이 **그대로인가**
- [ ] `agent.py` 안에 **API 키가 적혀 있지 않은가**

> **검수를 통과했다고 다 맞은 것이 아닙니다.**
> 검수 도구는 5가지만 기계적으로 봅니다. 나머지는 사람이 봐야 합니다.

## 잘 안 될 때

| 증상 | 이렇게 말하세요 |
|---|---|
| 설치하라는 패키지가 나왔다 | `추가 설치 없이 표준 라이브러리만 써서 다시 만들어줘` |
| 키를 넣으라는 코드가 생겼다 | `키를 코드에 적지 말고 환경 변수 OPENAI_API_KEY에서 읽어줘` |
| 브라우저 화면이 안 뜬다 | 폴더의 `run_report.html` 을 직접 더블클릭. 그래도 안 되면 터미널로 진행 |
| 화면이 갱신이 안 된다 | `run_report.html 에 meta refresh 1초를 넣어줘` |
| 한 번에 끝나고 `검수` 가 안 보인다 | `과제_저장 직후에는 반드시 결과_검수를 부르게 고쳐줘` |
| 도구를 부르는 순서가 고정돼 있다 | `도구 호출 순서를 코드에 박지 말고, 매 단계 AI가 JSON으로 정하게 해줘` |
| 안 멈추고 계속 돈다 | `최대 8단계, 재시도 2회 제한을 넣어줘` |
| 에러가 났다 | 실습 ④와 똑같이. **에러 전문을 통째로 복사해서 붙여넣기** |

- STEP 4 검수 9개 항목을 확인했다
