=========================================================
 실습 ⑤  에이전트 요구사항서
=========================================================

아래 "여기부터 ~ 여기까지"를 통째로 복사해서
Cursor 채팅창(Agent 모드)에 붙여넣으세요.

한 글자도 고치지 말고, 한 줄도 빠뜨리지 말고 그대로 넣습니다.
⚠️ 길다고 일부만 복사하면 에이전트가 안 만들어집니다.

직접 쓰는 연습은 뒤에 있는 【내 업무로 바꿔 쓰기】에서 합니다.

─────────────────────────────────────────────────────────
 여기부터 복사
─────────────────────────────────────────────────────────

이 폴더에 agent.py 를 만들어줘. 회의록에서 실행 과제를 뽑는 에이전트야.


[역할]
회의록을 읽고 → 실행 과제만 골라내고 → 담당자를 확인하고 →
todo.md 로 저장하고 → 저장 결과를 스스로 검수해서 → 통과할 때까지 고친다.


[회의록 선택]
프로그램을 시작하면 이 폴더의 .txt 파일 목록을 번호를 붙여 보여주고,
사용자가 번호를 입력하면 그 파일을 회의록으로 쓴다.
엔터만 치면 meeting.txt 를 쓴다.


[도구]
아래 4개를 파이썬 함수로 만들고, 에이전트가 필요할 때 골라 쓰게 해줘.

 1) 회의록_읽기()
    위에서 고른 회의록 전문을 돌려준다.

 2) 담당자_조회(표기)
    임직원_명부.json 에서 찾아 [{"이름","직급","부서"}, ...] 목록을 돌려준다.
    "박 대리" 처럼 성+직급으로도, "박민호" 처럼 이름으로도 찾을 수 있어야 한다.
    못 찾으면 빈 목록, 해당자가 여러 명이면 여러 개를 돌려준다.

 3) 과제_저장(과제목록)
    todo.md 로 저장한다. 표의 열은 [할 일 | 담당자 | 기한 | 비고] 4개.

 4) 결과_검수()
    저장된 todo.md 를 다시 읽어 아래 5가지를 기계적으로 검사하고
    {"통과": true/false, "사유": [...]} 를 돌려준다.
      ① 과제가 5건 이상인가
      ② 공지사항·잡담이 섞이지 않았는가
         (다음 회의 일정 / 점심 / 주차장 / 시스템 이관)
      ③ 담당자 열이 빈 칸인 행이 없는가
      ④ 기한 열이 빈 칸인 행이 없는가
      ⑤ 담당자가 "박 대리" 처럼 직함 표기로 남아 있지 않은가
         (정식 이름 또는 "미정" 이어야 한다)


[판단은 AI가 한다 — 이 항목이 제일 중요해]
매 단계마다 AI에게 "지금까지 한 일과 그 결과"를 보여주고,
다음에 무엇을 할지 아래 형식으로 딱 하나만 답하게 해.

   {"단계":"계획|도구사용|검수|완료",
    "도구":"도구이름",
    "입력": ...,
    "이유":"왜 지금 이걸 하는지 한 줄"}

파이썬은 그 도구를 실행한 결과를 다시 AI에게 돌려주고 또 물어본다.
어떤 도구를 쓸지, 쓸지 말지, 몇 번 쓸지는
파이썬 if 문이 아니라 AI가 정한다.
도구를 부르는 순서를 코드에 미리 박아넣지 마.


[검수 규칙]
과제_저장 을 한 직후에는 반드시 결과_검수() 를 부른다.
고치고 싶은 것이 있어도, 검수 결과를 본 다음에 고친다.


[규칙]
 - 회의록에 없는 담당자나 날짜를 지어내지 마. 모르면 "미정" 이라고 적어.
 - 담당자_조회 결과가 0명이거나 2명 이상이면 "미정" 으로 적고
   비고에 그 사유를 적어.
 - 비고의 사유는 그 항목에 해당하는 것만 적어.
   다른 항목의 사유를 그대로 복사하지 마.
 - "다음 주까지", "가능한 빨리" 같은 표현은 원문 그대로 적어.
   임의의 날짜로 바꾸지 마.
 - meeting.txt 와 임직원_명부.json 은 절대 수정하지 마.
 - API 키를 코드에 적지 말고 os.environ 의 OPENAI_API_KEY 에서 읽어.
 - 추가 설치 없이 파이썬 표준 라이브러리만 써. 모델은 gpt-4o-mini.


[화면 출력]
두 군데에 같은 내용을 보여준다.

 1) 터미널 — 매 단계 한 줄씩

      [계획] 무엇을 하려는지
      [도구] 도구이름(입력)  → 왜: 이유
      [실행] 결과 요약
      [검수] 통과 / 실패 + 사유

 2) run_report.html — 같은 내용을 카드 형태로

      · 매 단계가 끝날 때마다 파일 전체를 다시 쓴다
      · <meta charset="utf-8"> 와
        <meta http-equiv="refresh" content="1"> 를 넣는다
        (1초마다 브라우저가 스스로 새로고침한다)
      · CSS는 style 태그 안에 직접 쓴다.
        외부 라이브러리·폰트 금지, 50줄 이내. 꾸미는 데 시간 쓰지 마.
      · 검수 실패는 빨강, 통과는 초록으로 구분한다
      · 맨 위에 "n/8 단계" 진행 표시
      · 맨 아래에 todo.md 내용을 표로 보여준다
      · 프로그램 시작할 때 webbrowser 로 한 번만 연다
      · ⚠️ HTML 만들기에 실패하더라도
        터미널 출력과 에이전트 동작은 그대로 계속되어야 한다


[종료 조건]
 - 결과_검수가 통과하면 끝. 총 몇 건 / 담당자 미정 몇 건인지 보고해.
 - 최대 8단계까지만 돈다. 검수 실패 후 재시도는 2회까지.
 - 한도에 걸리면 "미완료" 라고 알리고 멈춘다.

─────────────────────────────────────────────────────────
 여기까지 복사
─────────────────────────────────────────────────────────


=========================================================
 만들어졌으면 실행
=========================================================

  python agent.py

  → 터미널에 회의록 목록이 뜹니다. 번호를 고르거나 엔터.
  → 브라우저 창이 열리고, 카드가 하나씩 쌓입니다.
  → 터미널에도 같은 내용이 찍힙니다. (화면이 안 뜨면 터미널을 보세요)


=========================================================
 【내 업무로 바꿔 쓰기】  ─ 시간이 남으면
=========================================================

위 요구사항서에서 바꿔야 할 곳은 사실 네 군데뿐입니다.
본인 업무로 바꿔 적어 보세요.

  [역할]      내 업무는 무엇을 → 무엇으로 바꾸는 일인가
              ________________________________________

  [도구]      그 일을 하려면 무엇을 읽고, 무엇을 쓰고,
              무엇을 확인해야 하는가 (3~4개)
              ________________________________________

  [규칙]      절대 지어내면 안 되는 것은 무엇인가
              ________________________________________

  [종료 조건]  무엇이 확인되면 "다 됐다" 라고 할 수 있는가
              ________________________________________

  ⚠️ 사내 대외비 내용은 넣지 마세요. 가상의 상황으로 적습니다.


=========================================================
 【더 해보기】  ─ 다 끝내고도 시간이 남으면
=========================================================

  ① 내 회의록으로 돌려보기
     가상의 회의록을 .txt 로 하나 만들어 이 폴더에 두고,
     프로그램을 다시 실행해 목록에서 골라 보세요.

  ② 버튼으로 실행하는 화면 만들기 (난이도 상)
     실습 노트북에는 Flask가 설치되어 있습니다.

        "app.py를 따로 만들어서, 브라우저에서 회의록을 고르고
         버튼을 누르면 agent.py가 실행되게 해줘.
         agent.py는 고치지 말고 그대로 불러 써.
         app.run(port=5000, debug=False) 로 실행하고,
         새로고침으로는 다시 실행되지 않게 해줘."

     ⚠️ agent.py 는 건드리지 마세요. 잘 돌아가는 것은 그대로 둡니다.
