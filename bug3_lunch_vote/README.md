# 버그 ③ 점심 메뉴 투표 페이지

## 이 프로그램이 하는 일

작은 웹 서버를 띄워서, 브라우저에서 점심 메뉴 투표 현황 페이지를 볼 수 있게 합니다.

## 실행 방법

Cursor에서 이 폴더를 열고, 터미널에 아래를 입력합니다.

```
python server.py
```

그리고 브라우저에서 **http://localhost:8000** 으로 접속합니다.

서버를 끄려면 터미널에서 **Ctrl + C** 를 누릅니다.

## 오늘의 과제

1. 서버를 켜고 브라우저에서 페이지를 확인합니다.
2. Cursor에게 이렇게 시킵니다 — **"점심 메뉴 목록에 비빔밥을 한 줄 추가해줘"**
3. 브라우저를 새로고침합니다.

**파일은 직접 열지 않습니다.** 수정은 Cursor가 합니다.

## 지금 상태

**Cursor가 분명히 메뉴를 추가했다고 하는데, 브라우저 화면이 바뀌지 않습니다.**
게다가 화면에 표시된 날짜도 오늘 날짜가 아닙니다.

이 버그는 **빨간 에러 메시지가 전혀 나오지 않습니다.**
그래서 "무엇을 복사해서 줄 것인가"가 아니라
**"내가 무엇을 했고 무엇이 그대로인지"를 설명하는 연습**입니다.

> Cursor 채팅에 5요소로 설명해 보세요.
>
> - 목표: 무엇을 만들려고 했나
> - 방금 한 일: 네가 어떤 파일을 어떻게 고쳤나
> - 기대: 무엇이 보이길 바랐나
> - 실제: 무엇이 보이나 (화면의 글자 그대로)
> - 확인 요청: "서버가 실제로 어떤 파일을 보여주고 있는지 확인해 줘"

## 완료 기준

- 브라우저에 **비빔밥이 추가된 화면**이 보인다
- Cursor에게 메뉴를 하나 더 추가시키고 새로고침하면 그 변경도 바로 반영된다
- 왜 반영이 안 됐었는지 한 문장으로 설명할 수 있다

## 참고

서버를 두 번 켜면 `Address already in use` 라는 에러가 날 수 있습니다.
이때는 이전 터미널에서 Ctrl + C 로 서버를 끈 다음 다시 실행하세요.
