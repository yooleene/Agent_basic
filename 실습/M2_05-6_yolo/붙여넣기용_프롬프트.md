## 프롬프트 3 — 완성 프롬프트 (교재 118p 예시: LLM이 만들어 준 결과)

STEP 2의 결과 대신 이 프롬프트를 Cursor에 바로 붙여넣어도 됩니다.

```
YOLOv11 Nano와 Flask를 활용한 가장 단순하고 직관적인 '사물 인식 웹 애플리케이션'을 만들어줘. 복잡한 클래스 구조나 불필요한 추상화 없이, 파일 하나만 봐도 흐름이 다 보일 정도로 직관적이고 깔끔한 코드를 원해.

아래 요구사항과 개발 환경을 엄격히 준수해서 한 번에 동작하는 코드를 작성해줘.
---
1. 개발 환경 및 라이브러리
- Backend: Flask
- Vision & AI: ultralytics (yolo11n.pt 자동 다운로드 활용), opencv-python
- Frontend: Single HTML (Tailwind CSS 활용, CSS 파일 분리 금지)

2. 폴더 구조
기본적인 Flask 구조를 따라 폴더와 파일을 생성해줘.
- app.py (Flask 메인 백엔드 소스)
- templates/index.html (프론트엔드 단일 페이지)

3. 핵심 기능 요구사항
[기능 1: 이미지 업로드 인식]
- 사용자가 이미지를 업로드하면 백엔드에서 YOLOv11n 모델로 객체를 감지함.
- 감지된 바운딩 박스와 클래스명이 그려진 결과 이미지를 웹 화면에 즉시 표시함. (복잡한 파일 저장 로직 대신, 메모리 내 또는 static 폴더를 활용한 심플한 방식으로 처리)

[기능 2: 웹캠 실시간 스트리밍]
- OpenCV(cv2.VideoCapture)를 사용해 웹캠 영상을 실시간으로 캡처함.
- 프레임마다 YOLOv11n 인식을 수행하고 바운딩 박스를 그린 뒤, Flask의 Multipart Response(generator 활용)를 통해 실시간 비디오 스트리밍 프레임으로 화면에 출력함.

4. UI/UX 디자인 요구사항
- `templates/index.html` 단일 파일로 작성하고 UI는 Tailwind CSS CDN을 활용해 깔끔하고 현대적인 대시보드 스타일로 디자인해줘.
- 좌측/우측 또는 상단/하단으로 2분할 레이아웃을 적용하여 [이미지 업로드 기능 구역]과 [실시간 웹캠 스트리밍 구역]이 직관적으로 한눈에 보이게 배치해줘.
- 웹캠 스트리밍은 '시작/종료' 상태를 직관적으로 알 수 있거나, 페이지 접속 시 바로 부드럽게 출력되도록 처리해줘.

5. 코드 작성 가이드라인
- 에러를 유발할 수 있는 복잡한 DB나 외부 종속성은 모두 배제하고 오직 Flask, OpenCV, Ultralytics 기본 기능만 사용해줘.
- app.py와 index.html 전체 코드를 생략 없이 '완전한 형태(Complete Code)'로 출력해줘.

[패키지 설치 규칙]
- requirements.txt 를 만들 때는 먼저 pip freeze 로 이 PC에 이미 설치된 패키지와 버전을 확인해.
- 이미 설치된 패키지는 설치된 버전을 그대로 적고(예: Flask==3.0.2), 업데이트하거나 다시 설치하지 마. 코드도 설치된 버전에 맞춰 작성해.
- 설치되어 있지 않은 패키지만 새로 설치하고, 설치할 때 -U(--upgrade) 옵션은 쓰지 마.
- 새 패키지를 설치하면서 이미 설치된 패키지의 버전이 바뀌게 되면, 설치하지 말고 나에게 먼저 알려줘.
```
