# 붙여넣기용 프롬프트 — CSS(Cascading Style Sheet)

아래 회색 상자를 **통째로 복사**해서 붙여넣으세요.

---

## 코드 1 — CSS 적용 전

```html
관심종목<br>
<ul>
    <li>키움증권</li>
    <li>대신증권</li>
    <li>미래에셋대우</li>
</ul>
```

---

## 코드 2 — CSS 적용 후

```html
<style>
li {
    width: 120px;
    margin: 8px;
    padding-bottom: 4px;
    font-weight: bold;
    color: olive;
    border-bottom: 1px solid #ccc;
}
</style>

관심종목<br>
<ul>
    <li>키움증권</li>
    <li>대신증권</li>
    <li>미래에셋대우</li>
</ul>
```
