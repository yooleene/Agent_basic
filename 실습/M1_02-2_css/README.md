# CSS(Cascading Style Sheet)

**2. 웹 이해** · 개인 실습

---

## 이 실습에서 할 일

같은 HTML에 CSS를 입히면 화면이 어떻게 달라지는지 비교합니다. **HTML = 내용, CSS = 디자인**.

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `붙여넣기용_프롬프트.md` | 복사해서 쓸 프롬프트·코드 |

---

## 진행 순서

### STEP 1 · CSS 적용 전

새 파일 **`style.html`** 을 만들고 **코드 1**을 붙여넣어 저장 → 탐색기에서 더블클릭해 확인합니다.

### STEP 2 · CSS 적용 후

파일 내용을 **코드 2**로 바꿔 저장 → 브라우저 새로고침. 무엇이 달라졌나요?

### STEP 3 · 바꿔 보기

`color: olive` 를 `color: navy` 로, `width: 120px` 를 `200px` 로 바꿔 보세요.

---

## 완료 기준

- CSS 적용 전·후 화면 차이를 확인했다
- 색상·폭 값을 바꿔 결과를 확인했다
