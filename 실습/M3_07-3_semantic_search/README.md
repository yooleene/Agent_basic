# 실습 ③ 의미 검색 체험하기

**10분** · 개인 또는 조별

---

## 이 실습에서 할 일

실습 ②에서 AI에게 9쪽짜리 문서를 통째로 줬습니다.
그런데 **문서가 900쪽이면?** 통째로 못 줍니다.

그래서 RAG는 문서를 조각내 두고, **질문과 뜻이 가까운 조각만 골라서** 줍니다.
그 "뜻이 가깝다"를 컴퓨터가 어떻게 판단하는지 직접 겪어보는 시간입니다.

## 진행 순서

| 시간 | 할 일 |
|---|---|
| 0-3분 | **라운드 1** — 사람이 먼저 순위를 매긴다 → AI에게 시켜본다 |
| 3-7분 | **라운드 2** — 단어가 하나도 안 겹치는 질문으로 찾아본다 |
| 7-10분 | 정리 — 키워드 검색과 뭐가 다른가 |

**`붙여넣기용_프롬프트.md`** 를 열면 Cursor에 그대로 복사할 프롬프트가 있습니다.

## 준비

Cursor 채팅을 **새 채팅**으로 시작하세요.
이 실습은 문서를 참조하지 않습니다. 프롬프트에 문장을 직접 붙여넣습니다.

# 라운드 1 · 순위 매기기

## 기준 질문

> **"재택근무는 며칠 전에 신청해야 하나요?"**

## 후보 문장 4개

아래는 한빛소재 규정집에서 뽑은 실제 문장입니다.

| # | 문장 |
|---|---|
| ① | 해외 출장자는 출발 14일 전까지 출장계획서를 제출하여야 한다 |
| ② | 임직원은 월 8일의 범위에서 재택근무를 할 수 있다 |
| ③ | 중식은 구내식당에서 무료로 제공하며, 외부 식사 시 1일 9,000원 한도로 지원한다 |
| ④ | 재택근무를 하려는 자는 희망일의 3근무일 전까지 그룹웨어로 신청하고 팀장의 승인을 받아야 한다 |

## STEP 1 · 내가 먼저 (2분)

기준 질문에 **답이 되는 순서**로 번호를 적으세요.

> 1위 ____  2위 ____  3위 ____  4위 ____

## STEP 2 · AI에게 시키기 (2분)

`붙여넣기용_프롬프트.md` 의 **프롬프트 1** 을 복사해 Cursor에 붙여넣으세요.

## STEP 3 · 비교 (1분)

| | 1위 | 2위 | 3위 | 4위 |
|---|---|---|---|---|
| 내 순위 | | | | |
| AI 순위 | | | | |

### 여기서 볼 것

- **①번을 보세요.** "○일 전까지 신청/제출"이라는 **문장 구조가 기준 질문과 똑같습니다.**
  단어만 세면 아주 비슷해 보입니다. 그런데 순위는요?
- **②번을 보세요.** "재택근무"라는 단어가 들어 있습니다. 그런데 **"며칠 전에 신청"에 대한
  답은 아닙니다.** AI는 이걸 구분했나요?

> 단어가 겹치는 것과 **뜻이 맞는 것**은 다릅니다.

# 라운드 2 · 단어가 하나도 안 겹칠 때

## 기준 질문

> **"휴가 갈 때 회사에서 돈을 주나요?"**

이 질문에는 규정집에 쓰인 단어가 **하나도 없습니다.**
"휴가 갈 때"도, "돈을 주나요"도 문서에 그대로는 안 나옵니다.

## 후보 문장 4개

| # | 문장 |
|---|---|
| ① | 회사는 연차휴가와 별도로 5일의 하계휴가를 부여한다 |
| ② | 하계휴가 사용을 지원하기 위하여 매년 7월 급여 지급일에 하계휴가 지원금을 지급한다 |
| ③ | 경조사비는 사유 발생일로부터 60일 이내에 신청하여야 하며, 증빙서류를 첨부한다 |
| ④ | 리프레시 휴가 사용자에게는 장기근속 포상금과 별도로 휴가 지원금 50만원을 지급한다 |

## STEP 1 · Ctrl+F 로 찾아보기 (1분)

만약 이 문서에서 **"돈"** 을 Ctrl+F로 검색한다면 몇 개가 나올까요?

> ______ 개

**"휴가 갈 때"** 는요?

> ______ 개

## STEP 2 · AI에게 시키기 (2분)

`붙여넣기용_프롬프트.md` 의 **프롬프트 2** 를 복사해 붙여넣으세요.

## STEP 3 · 확인 (1분)

AI가 고른 1·2위는 몇 번이었나요?

> ______ 번, ______ 번

### 여기서 볼 것

**"휴가"와 "돈" 두 조건을 모두 만족하는 문장**이 위로 올라왔을 겁니다.
③번은 "돈" 이야기지만 휴가가 아니고, ①번은 "휴가" 이야기지만 돈이 아닙니다.

> Ctrl+F로는 **0건**이었을 질문에서,
> 의미 검색은 정확한 조항을 찾아냈습니다.

# 정리

| | 키워드 검색 (Ctrl+F) | 의미 검색 (임베딩) |
|---|---|---|
| 찾는 방식 | 글자가 똑같이 들어있는 곳 | 뜻이 가까운 곳 |
| "돈" 으로 검색 | 0건 | 지원금·포상금 조항을 찾아냄 |
| "○일 전까지 신청" | 출장 조항도 같이 나옴 | 재택근무 조항을 위로 올림 |
| 한계 | 단어를 정확히 알아야 함 | 엉뚱하게 가까운 문장이 섞이기도 함 |

## 한 문장으로

문서를 조각내고, 조각마다 **뜻의 좌표**를 매겨두면,
질문이 들어왔을 때 **좌표가 가까운 조각만** 골라낼 수 있습니다.

> 그 좌표를 매기는 일 = **임베딩**
> 조각내는 일 = **청킹**
> 좌표를 담아두는 창고 = **벡터DB**
> 가까운 조각을 골라내는 일 = **검색(Retriever)**

**10번 시간에 Cursor에게 시킬 단어가 이 네 개입니다.**

## ⚠️ 참고

이 실습은 LLM에게 "의미 순위를 매겨달라"고 부탁해서 **간접 체험**하는 방식입니다.
실제 RAG는 숫자 좌표를 계산해 거리를 재기 때문에 원리가 100% 같지는 않습니다.
다만 **"단어가 아니라 뜻으로 찾는다"** 는 감을 잡기에는 충분합니다.
