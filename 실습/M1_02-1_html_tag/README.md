# HTML Tag의 기본 구조

**2. 웹 이해** · 개인 실습

---

## 이 실습에서 할 일

웹페이지의 뼈대인 HTML 태그(`html`, `head`, `title`, `body`)가 브라우저에서 어떻게 보이는지 직접 확인합니다.

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `붙여넣기용_프롬프트.md` | 복사해서 쓸 프롬프트·코드 |

---

## 진행 순서

### STEP 1 · 파일 만들기

Cursor에서 이 폴더를 열고 새 파일 **`index.html`** 을 만듭니다.

### STEP 2 · 코드 붙여넣기

`붙여넣기용_프롬프트.md` 의 코드를 복사해 붙여넣고 저장(Ctrl+S)합니다.

### STEP 3 · 브라우저로 열기

탐색기에서 `index.html` 을 **더블클릭**합니다.
- 브라우저 **탭 제목**에 무엇이 보이나요? → `<title>`
- **화면 본문**에 무엇이 보이나요? → `<body>`

### STEP 4 · 바꿔 보기

`Hello World!` 를 내 이름으로 바꾸고 저장 → 브라우저 **새로고침(F5)**.

---

## 완료 기준

- `<title>` 과 `<body>` 내용이 각각 어디에 나타나는지 확인했다
- 코드를 고치고 새로고침해 변경을 확인했다
