# 붙여넣기용 프롬프트 — 이미지 사이즈 및 컬러 조정 앱

아래 회색 상자를 **통째로 복사**해서 붙여넣으세요.

---

## 프롬프트 1 — 요구사항 정리 (ChatGPT 등 LLM 채팅창에 입력)

```
아래 내용을 참고해서 개발환경, 노드(기능), UI로 구분해줘
=====
이미지를 업로드하면 사이즈 및 컬러 조정하는 앱을 만들거야

 - pyqt5 활용
 - 여러 이미지 업로드
 - 컬러조정 : RGB 바를 이용해 실시간으로 이미지 컬러 조정, 버튼으로 흑백 변경
 - 크기 조정 : 이미지 사이즈를 x,y 픽셀을 입력하여 크기 조정, 
                        가로 또는 세로 사이즈 조정시 다른 사이즈 자동 설정,
                        하나의 이미지 사이즈 설정시 다른 이미지도 동일한 사이즈로 일괄 적용  
 - 결과 저장 : 수정된 결과를 jpg, png, gif 등으로 저장
```

---

## 프롬프트 2 — Cursor용 프롬프트 만들기 (LLM에 입력 → 나온 결과를 Cursor에 붙여넣기)

```
아래 내용을 참고해서 Cursor에 넣을 프롬프트 만들어.
이미지 사이즈 및 컬러 조정하는 앱을 만들거야
1. 개발환경
  - PyQt5 활용

2. 노드설명
  - 이미지 업로드 (다중 업로드 지원)
  - 하나의 이미지를 수정하면 동일한 기준으로 다른 이미지에도 일괄 적용
  - 컬러 조정: RGB 바를 이용해 실시간으로 이미지 컬러 조정
  - 크기 조정: x사이즈 입력 시 비율에 맞춰 y사이즈 자동 조정
  - 흑백 변환 기능
  - 결과 저장: 수정된 결과를 jpg, png, gif 등으로 저장

3. UI설명
  - 다중 이미지 업로드 UI
  - RGB 슬라이더 바 (실시간 컬러 조정)
  - x 픽셀 입력창 / y사이즈 자동 계산 표시
  - 흑백 변환 버튼
  - 저장 형식 선택 (jpg, png, gif 등)
```

## 패키지 설치 규칙 — Cursor에 붙여넣을 때 프롬프트 맨 끝에 함께 붙여넣으세요

이 PC에 이미 설치된 패키지를 그대로 쓰게 하는 규칙입니다.

```

[패키지 설치 규칙]
- requirements.txt 를 만들 때는 먼저 pip freeze 로 이 PC에 이미 설치된 패키지와 버전을 확인해.
- 이미 설치된 패키지는 설치된 버전을 그대로 적고(예: Flask==3.0.2), 업데이트하거나 다시 설치하지 마. 코드도 설치된 버전에 맞춰 작성해.
- 설치되어 있지 않은 패키지만 새로 설치하고, 설치할 때 -U(--upgrade) 옵션은 쓰지 마.
- 새 패키지를 설치하면서 이미 설치된 패키지의 버전이 바뀌게 되면, 설치하지 말고 나에게 먼저 알려줘.
```
