# to-spec 스킬 — 요구사항 문서(SPEC.md) 생성

**6. 바이브코딩 스킬 활용** · 개인 실습

---

## 이 실습에서 할 일

grill-me로 구체화한 대화 내용을 바탕으로 **개발 기준이 정리된 SPEC.md(PRD)** 파일을 만듭니다.

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `붙여넣기용_프롬프트.md` | 복사해서 쓸 프롬프트·코드 |

---

## 진행 순서

### STEP 1 · 스킬 설치

Cursor Agent 채팅에 링크를 주고 `이 스킬 설치해줘`

### STEP 2 · SPEC.md 만들기

grill-me 대화를 한 **같은 채팅**에서 `/to-spec` 을 호출하고 프롬프트를 입력합니다.

```
/to-spec 지금까지 내용을 SPEC.md파일에 작성해줘
```

### STEP 3 · 빠진 항목 점검

SPEC.md에 아래가 있는지 확인하고, 없으면 추가를 요청합니다.
- 데이터 모델/스키마
- 에러·예외 처리 기준
- 인증/권한
- 비기능 요구사항(사용자 규모, 성능)

---

## 완료 기준

- SPEC.md 파일이 생겼고 빠진 항목을 보완했다
