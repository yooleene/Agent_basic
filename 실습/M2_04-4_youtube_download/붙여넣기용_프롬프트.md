# 붙여넣기용 프롬프트 — 유튜브 영상 다운로드 앱

아래 회색 상자를 **통째로 복사**해서 붙여넣으세요.

---

## 프롬프트 1 — 요구사항 정리 (ChatGPT 등 LLM 채팅창에 입력)

```
아래 내용을 참고해서 개발환경, 노드(기능), UI로 구분해줘
=====
유튜브 영상 링크를 붙여넣기 하면 해당 영상을 다운로드 하는 앱을 만들거야

 - Python으로 YouTube 링크를 입력하면 영상 또는 음원을 다운로드할 수 있는 GUI 앱을 만들어줘
 - GUI 프레임워크는 PyQt5 사용
 - 영상/음원 정보 분석 및 다운로드는 yt-dlp 패키지 사용
 - 사용자가 유튜브 링크 입력, 다운로드 폴더 선택 
 - “분석” 버튼 클릭 → yt-dlp로 해당 링크 분석 후 가능한 다운로드 포맷 리스트 출력
 - 사용자가 포맷 선택
 - “다운로드” 버튼 클릭 → 선택한 포맷으로 영상 또는 음원 다운로드
 - UI는 심플하게 구성
```

## 프롬프트 2 — Cursor용 프롬프트 만들기 (LLM에 입력 → 나온 결과를 Cursor에 붙여넣기)

```
아래 내용을 참고해서 Cursor에 넣을 프롬프트 만들어.
유튜브 영상 링크를 붙여넣기 하면 해당 영상을 다운로드 하는 앱을 만들거야
1. 개발환경
  - Python 사용
  - GUI 프레임워크: PyQt5
  - 영상/음원 분석 및 다운로드: yt-dlp 패키지

2. 노드설명
  - 유튜브 링크 입력
  - 다운로드 폴더 선택
  - "분석" 버튼 클릭 시 yt-dlp로 링크 분석 후 가능한 다운로드 포맷 리스트 출력
  - 사용자가 포맷 선택
  - "다운로드" 버튼 클릭 시 선택한 포맷으로 영상 또는 음원 다운로드

3. UI설명
  - 심플한 UI 구성
  - 유튜브 링크 입력창
  - 다운로드 폴더 선택 메뉴
  - 분석 버튼
  - 포맷 리스트 출력 영역
  - 다운로드 버튼
```

## 패키지 설치 규칙 — Cursor에 붙여넣을 때 프롬프트 맨 끝에 함께 붙여넣으세요

이 PC에 이미 설치된 패키지를 그대로 쓰게 하는 규칙입니다.

```

[패키지 설치 규칙]
- requirements.txt 를 만들 때는 먼저 pip freeze 로 이 PC에 이미 설치된 패키지와 버전을 확인해.
- 이미 설치된 패키지는 설치된 버전을 그대로 적고(예: Flask==3.0.2), 업데이트하거나 다시 설치하지 마. 코드도 설치된 버전에 맞춰 작성해.
- 설치되어 있지 않은 패키지만 새로 설치하고, 설치할 때 -U(--upgrade) 옵션은 쓰지 마.
- 새 패키지를 설치하면서 이미 설치된 패키지의 버전이 바뀌게 되면, 설치하지 말고 나에게 먼저 알려줘.
```
