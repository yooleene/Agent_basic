# 실습 2 · Local LLM, 임베딩 모델 활용 RAG 구현

**50분** · 개인 실습

---

## 오늘 만들 것

실습 1과 **같은 RAG 챗봇**을, 이번에는 **인터넷·API 키 없이 내 PC 안에서만** 돌아가게 만듭니다.
LLM과 임베딩 모델을 PC에 내려받아 사용합니다.

| 구분 | 실습 1 (General) | 실습 2 (Local) |
|---|---|---|
| LLM | `gpt-4o-mini` (OpenAI API) | **EXAONE-3.5-2.4B-Instruct** (GGUF, Q5_K_M) |
| 임베딩 | `text-embedding-3-small` (OpenAI API) | **BAAI/bge-m3** |
| 실행 방식 | 클라우드 호출 | `llama-cpp-python` 으로 로컬 실행 |
| 장점 | 답변 품질 좋음, 빠름 | 문서가 외부로 나가지 않음, 비용 없음 |
| 한계 | 문서가 외부 서버로 전송됨 | 소형 모델이라 복잡한 추론에 한계, CPU에선 느림 |

| 모델 | 크기 | 특징 |
|---|---|---|
| BAAI/bge-m3 (임베딩) | 약 1GB 이내 | 다국어·한국어 지원 우수, CPU에서도 동작 |
| EXAONE-3.5-2.4B-Instruct-GGUF (LLM) | 약 1.8GB 이내 | LG AI Research, 한국어·영어 이중언어 최적화 |

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `models/` | 모델을 내려받을 폴더 (처음엔 비어 있음) |
| `2022년 버전 선재 카탈로그_국문_최종.pdf` | 업로드 테스트용 문서 |
| `붙여넣기용_프롬프트.md` | Cursor에 붙여넣을 프롬프트 |

## 진행 순서

### STEP 1 · 모델 다운로드 (10분)

1. 탐색기로 **`M3_08-2_local_rag\models`** 폴더로 이동 → 주소창에 `cmd` 입력 → 엔터
2. 허깅페이스 패키지 설치

```
pip install huggingface_hub
```

3. 임베딩 모델 다운로드

```
hf download BAAI/bge-m3 --local-dir bge-m3
```

4. LLM 다운로드

```
hf download LGAI-EXAONE/EXAONE-3.5-2.4B-Instruct-GGUF --include "*Q5_K_M.gguf" --local-dir exaone_2.4b
```

다운로드가 끝나면 폴더 구조가 이렇게 되어야 합니다.

```
M3_08-2_local_rag
 └ models
    ├ bge-m3\ ...
    └ exaone_2.4b\EXAONE-3.5-2.4B-Instruct-Q5_K_M.gguf
```

> 강사가 모델 파일을 미리 배포한 경우 STEP 1은 건너뛰고 `models` 폴더에 복사만 하세요.

### STEP 2 · 개발 환경 준비 (3분)

1. 터미널에서 한 단계 위(`M3_08-2_local_rag`)로 이동

```
cd ..
pip list > requirements.txt
```

2. Cursor에서 **File → Open Folder → `M3_08-2_local_rag`** 폴더를 엽니다.

### STEP 3 · 프롬프트 입력 (10분)

`붙여넣기용_프롬프트.md` 의 **프롬프트 2**를 통째로 복사해 Cursor 채팅(Agent 모드)에 붙여넣습니다.

> 붙여넣기 전에 프롬프트 안의 **모델 경로**가 STEP 1의 폴더 구조와 같은지 확인하세요.
> 경로가 하나라도 다르면 모델을 못 찾습니다.

### STEP 4 · 실행 & 테스트 (15분)

```
python app.py
```

실습 1과 **같은 PDF, 같은 질문**으로 테스트하고 비교해 보세요.

| 비교 항목 | 실습 1 (GPT) | 실습 2 (EXAONE) |
|---|---|---|
| 답변 속도 | | |
| 답변 정확도 | | |
| 참고 chunk·페이지 | | |
| 문서에 없는 질문 처리 | | |

### STEP 5 · 보완 & 파라미터 조정 (12분)

동작을 확인했다면 아래 중 하나를 골라 바꿔 보세요.

- 청크 크기: 500 → 300 또는 800 으로 바꾸면 답이 어떻게 달라지는가
- LLM 파라미터: `temperature`, `max_tokens`, `n_ctx` 조정
- 화면 디자인 보완

## 잘 안 될 때

| 증상 | 이렇게 말하세요 |
|---|---|
| 이미 설치된 패키지를 업데이트·재설치하려 한다 (`-U`, `--upgrade`, 다른 버전 지정) | 승인하지 말고 **거절**한 뒤 `이미 설치된 패키지는 업데이트하지 말고 설치된 버전을 그대로 써줘` |
| 모델 파일을 못 찾는다 | `models 폴더 구조를 확인하고, 실제 파일 경로에 맞게 코드를 고쳐줘` |
| `llama-cpp-python` 설치 실패 | 에러 전문을 복사해서 붙여넣고 `설치 방법을 알려줘` |
| 답변이 너무 느리다 | `n_ctx를 줄이고, 검색 chunk 수를 3개로 줄여줘` |
| 답변이 영어로 나온다 | `답변은 반드시 한국어로 하도록 시스템 프롬프트에 넣어줘` |
| 문서에 없는 내용도 지어서 답한다 | `관련 chunk가 없으면 "정보가 없어서 답변할 수 없습니다"라고만 답하게 고쳐줘` |

## 완료 기준

- `models` 폴더에 두 모델이 내려받아져 있다
- 인터넷 API 호출 없이 업로드 → 질문 → 답변 + 참고 chunk 출력까지 확인했다
- 실습 1과 결과를 비교해 표를 채웠다
