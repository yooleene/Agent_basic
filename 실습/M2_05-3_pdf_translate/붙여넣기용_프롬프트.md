## 프롬프트 3 — 완성 프롬프트 (교재 97p 예시: LLM이 만들어 준 결과)

STEP 2의 결과 대신 이 프롬프트를 Cursor에 바로 붙여넣어도 됩니다.

```
너는 파이썬 및 Flask 웹 개발 전문가야. 아래의 요구사항을 바탕으로 PDF 파일의 텍스트를 추출해 번역하고, 
결과를 텍스트 파일로 저장할 수 있는 웹 애플리케이션 코드를 작성해 줘.

# 기술 스택
- Backend: Python, Flask
- PDF 텍스트 추출: pypdf (또는 PyPDF2)
- 번역 API: OpenAI API (openai 패키지)

# UI/UX 및 화면 레이아웃 요구사항 (ChatGPT 스타일의 2단 분할 화면)
화면을 좌/우 두 개의 영역으로 분할하여 데스크톱에서 보기 좋게 구성해.

1. 왼쪽 패널 (컨트롤 및 진행 상태):
   - PDF 파일 업로드 폼
   - 번역 방향 설정 (영어 -> 한국어, 한국어 -> 영어 선택 라디오 버튼 또는 드롭다운)
   - '번역 시작' 버튼
   - 번역 진행률(%)을 실시간으로 보여주는 프로그레스 바 또는 텍스트

2. 오른쪽 패널 (미리보기 및 다운로드):
   - 'PDF에서 추출한 텍스트'를 보여주는 스크롤 가능한 미리보기 영역 (Textarea 또는 div)
   - '번역된 내용'을 보여주는 스크롤 가능한 미리보기 영역 (Textarea 또는 div)
   - 번역 완료 시 활성화되는 '다운로드' 버튼

3. 스타일링:
   - 배경이 어두운 색이면 글자 색깔을 흰색으로, 배경이 밝은 색이면 글자 색깔을 검은색으로 자동 적용되도록 CSS를 작성해.
   - 좌우 패널이 깔끔하게 나뉘도록 Flexbox나 Grid를 활용해 직관적으로 디자인해.

# 핵심 기능 요구사항
1. PDF 텍스트 추출 및 번역 연동:
   - pypdf를 이용해 업로드된 PDF 파일에서 '텍스트'만 추출해.
   - OpenAI API를 사용하여 추출된 텍스트를 선택한 언어로 번역해.
   - API Key는 절대 하드코딩하지 말고, 시스템 환경 변수에 저장된 ‘OPENAI_API_KEY’를 ‘os.environ’으로 불러와서 사용해.

2. 번역 진행률 표시 및 실시간 렌더링 (SSE):
   - 텍스트를 페이지 단위나 적절한 청크 단위로 나누어 번역을 진행해.
   - 번역이 진행되는 동안 왼쪽 패널의 진도율이 업데이트되고, 동시에 오른쪽 패널의 '번역된 내용' 영역에 텍스트가 실시간으로 추가되도록 SSE(Server-Sent Events)나 AJAX 폴링을 구현해.

3. 텍스트 파일(.txt) 저장 및 다운로드:
   - 번역이 완료되면 오른쪽 패널의 다운로드 버튼을 통해 번역된 텍스트 파일(.txt)을 받을 수 있게 해.
   - 다운로드되는 텍스트 파일의 이름은 업로드한 원본 PDF 파일의 이름과 동일하게 설정해 (예: ‘report.pdf’ 업로드 시 `report.txt`로 다운로드).

# 출력 지침
- ‘app.py’, ‘templates/index.html’ 코드와 필요한 폴더 구조를 명확히 나누어 작성해 줘.
- 코드를 실행하기 위해 설치해야 하는 ‘requirements.txt’ 내용과 터미널 실행 명령어도 함께 안내해 줘.

[패키지 설치 규칙]
- requirements.txt 를 만들 때는 먼저 pip freeze 로 이 PC에 이미 설치된 패키지와 버전을 확인해.
- 이미 설치된 패키지는 설치된 버전을 그대로 적고(예: Flask==3.0.2), 업데이트하거나 다시 설치하지 마. 코드도 설치된 버전에 맞춰 작성해.
- 설치되어 있지 않은 패키지만 새로 설치하고, 설치할 때 -U(--upgrade) 옵션은 쓰지 마.
- 새 패키지를 설치하면서 이미 설치된 패키지의 버전이 바뀌게 되면, 설치하지 말고 나에게 먼저 알려줘.
```
