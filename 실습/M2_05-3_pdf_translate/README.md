# PDF 번역 웹

**5. 바이브코딩 기반 웹 개발** · 개인 실습

---

## 이 실습에서 할 일

PDF를 올리면 텍스트를 추출해 **OpenAI API로 번역**하고, 진도율을 보여 주며 결과를 텍스트 파일로 저장하는 Flask 웹을 만듭니다.

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `20250930_[월간 리서치] 철강_part_2.pdf` | 번역 테스트용 PDF (교재 103p) |
| `붙여넣기용_프롬프트.md` | 복사해서 쓸 프롬프트·코드 |

---

## 진행 순서

### STEP 1 · API 키 확인

시스템 환경 변수에 `OPENAI_API_KEY` 가 설정되어 있어야 합니다. 터미널에서 `echo %OPENAI_API_KEY%` 로 확인하세요.

### STEP 2 · 요구사항 정리

`붙여넣기용_프롬프트.md` 의 **프롬프트 1**을 ChatGPT(또는 Cursor 채팅)에 붙여넣습니다.
AI가 요구사항을 **개발환경 / 노드(기능) / UI** 세 덩어리로 나눠 줍니다.

> 막연한 요구사항이 세 덩어리로 정리되는 과정을 눈으로 확인하세요.

### STEP 3 · Cursor용 프롬프트 만들기

**프롬프트 2**를 붙여넣어 Cursor에 넣을 최종 프롬프트를 만듭니다.
결과가 마음에 들지 않으면 빠진 기능을 직접 한 줄 추가해도 됩니다.

> 교재 97p의 완성 예시가 **프롬프트 3**에 있습니다. 비교해 보거나 그대로 사용하세요.

### STEP 4 · Cursor로 개발

Cursor에서 **File → Open Folder → 이 폴더**를 열고, 채팅을 **Agent 모드**로 둔 뒤 STEP 2의 결과를 붙여넣습니다.
**이때 프롬프트 맨 끝에 `붙여넣기용_프롬프트.md` 의 `패키지 설치 규칙`을 함께 붙여넣습니다.**
패키지 설치·파일 생성 승인 요청이 나오면 **승인**합니다.

### STEP 5 · 실행

`python app.py` → 터미널 주소 **Ctrl + 클릭**

### STEP 6 · 동작 테스트

- [ ] PDF를 올리면 원문 텍스트 미리보기가 나온다
- [ ] 영→한 / 한→영 방향을 고를 수 있다
- [ ] 번역 진도율이 올라간다
- [ ] 번역 결과 미리보기가 나온다
- [ ] 저장된 txt 파일명이 PDF 파일명과 같다

### STEP 7 · 에러가 나면

**STOP · COPY · TELL** — 멈추고, 에러 전문(또는 화면 캡처)을 통째로 복사해서, 무엇을 하다가 그랬는지 한 줄 붙여 Cursor에 전달합니다.

## 잘 안 될 때

| 증상 | 이렇게 하세요 |
|---|---|
| 이미 설치된 패키지를 업데이트·재설치하려 한다 (`-U`, `--upgrade`, 다른 버전 지정) | 승인하지 말고 **거절**한 뒤 `이미 설치된 패키지는 업데이트하지 말고 설치된 버전을 그대로 써줘` |
| `ModuleNotFoundError` | `필요한 패키지를 설치해줘` |
| API 키를 넣으라는 코드가 생겼다 | `키는 코드에 적지 말고 환경 변수 OPENAI_API_KEY에서 읽어줘` |
| 화면이 기대와 다르다 | 화면을 캡처해 붙여넣고 `이 부분을 ~처럼 바꿔줘` |
| 같은 에러가 3번 반복된다 | **새 채팅**을 열고 문제를 작게 쪼개서 다시 요청 |
| 번역이 너무 오래 걸린다 | `앞의 3페이지만 번역하는 테스트 옵션을 추가해줘` |
