# 제1장 총칙

### 제1조 (목적)

이 안내서는 한빛소재 주식회사(이하 "회사") 임직원의 근무제도와 복리후생 제도의
기준 및 절차를 정함을 목적으로 한다.

### 제2조 (적용 범위)

1. 이 안내서는 회사에 재직 중인 모든 정규직 임직원에게 적용한다.
2. 계약직 직원에게는 제2장(근무제도)과 제3장(휴가)을 적용하며, 제4장(복리후생)은
   계약기간이 1년 이상인 경우에 한하여 적용한다.
3. 파견 및 도급 인력에게는 이 안내서를 적용하지 아니한다.

### 제3조 (용어의 정의)

| 용어 | 정의 |
|---|---|
| 근속연수 | 입사일로부터 기산한 재직 기간. 휴직 기간은 산입하지 아니한다 |
| 근무일 | 토요일, 일요일 및 법정공휴일을 제외한 날 |
| 팀장 | 팀 단위 조직의 장. 부재 시 차상위 조직장이 직무를 대행한다 |
| 코어타임 | 전 직원이 반드시 근무해야 하는 시간대 |

# 제2장 근무제도

### 제4조 (기본 근무시간)

1. 1일 소정근로시간은 8시간, 1주 소정근로시간은 40시간으로 한다.
2. 기본 근무시간은 **08:30부터 17:30까지**로 하며, 휴게시간은 **12:00부터 13:00까지** 1시간으로 한다.
3. 생산 현장의 교대 근무자는 별도의 교대근무 기준표에 따른다.

### 제5조 (유연근무제)

1. 회사는 시차출퇴근제를 운영하며, 임직원은 아래 3개 유형 중 하나를 선택할 수 있다.

   | 유형 | 출근 | 퇴근 |
   |---|---|---|
   | A형 | 07:30 | 16:30 |
   | B형 (기본) | 08:30 | 17:30 |
   | C형 | 09:30 | 18:30 |

2. **코어타임은 10:00부터 15:00까지**이며, 이 시간에는 유형과 관계없이 전원 근무하여야 한다.
3. 유형 변경은 **월 1회**에 한하여 가능하며, 변경하려는 달의 **전월 25일까지**
   그룹웨어를 통해 신청한다.

### 제6조 (재택근무)

1. 임직원은 **월 8일**의 범위에서 재택근무를 할 수 있다.
2. 재택근무를 하려는 자는 **희망일의 3근무일 전까지** 그룹웨어로 신청하고
   팀장의 승인을 받아야 한다.
3. **연속 재택근무는 3일을 초과할 수 없다.**
4. 다음 각 호의 경우에는 재택근무를 신청할 수 없다.
   - 입사 후 3개월이 경과하지 아니한 자
   - 생산 현장 교대 근무자
   - 당일 사내 필수 교육이 예정된 자
5. 재택근무일에도 코어타임 중에는 상시 연락이 가능한 상태를 유지하여야 한다.

### 제7조 (연장근무 및 야근 식대)

1. 연장근무는 사전에 팀장의 승인을 받아야 하며, 월 52시간을 초과할 수 없다.
2. **18:30 이후까지 연장근무한 경우 1회당 12,000원의 야근 식대**를 지급한다.
3. 야근 식대는 익월 급여에 합산하여 지급한다.
4. 휴일 근무 시에는 식대와 별도로 교통비 20,000원을 지급한다.

# 제3장 휴가

### 제8조 (연차유급휴가)

1. 연차유급휴가는 근로기준법이 정하는 바에 따라 부여한다.
   - 계속근로기간 1년 미만인 자: 1개월 개근 시 1일
   - 계속근로기간 1년 이상인 자: 15일
   - 이후 매 2년마다 1일을 가산하며, 가산휴가를 포함한 총 휴가일수는 25일을 한도로 한다.
2. 회사는 위 법정 휴가에 더하여, **근속 5년 이상인 자에게 매년 2일의 특별가산휴가**를
   추가로 부여한다. 특별가산휴가는 제1항의 25일 한도에 산입하지 아니한다.
3. 연차휴가는 **1시간 단위로 분할 사용**할 수 있다. 단, 1일 4시간 이상 사용하는 경우
   반차로 처리한다.
4. 미사용 연차휴가는 다음 연도로 이월할 수 없으며, 연차수당으로 정산한다.

### 제9조 (하계휴가)

1. 회사는 연차휴가와 **별도로 5일의 하계휴가**를 부여한다.
2. 하계휴가는 **7월 1일부터 9월 30일 사이**에 사용하여야 한다.
3. 하계휴가는 다음 연도로 이월할 수 없으며, 미사용 시 수당으로 정산하지 아니한다.
4. 부서별 업무 공백을 방지하기 위하여 같은 팀에서 동시에 하계휴가를 사용하는 인원은
   팀 정원의 3분의 1을 초과할 수 없다.

### 제10조 (경조사 휴가)

| 구분 | 대상 | 휴가일수 |
|---|---|---|
| 결혼 | 본인 | 5일 |
| | 자녀 | 1일 |
| | 형제자매 | 1일 |
| 출산 | 배우자 출산 | 10일 |
| 사망 | 배우자, 본인 및 배우자의 부모 | 5일 |
| | 본인 및 배우자의 조부모, 형제자매 | 3일 |
| | 자녀 및 그 배우자 | 5일 |
| 기타 | 본인 및 배우자 부모의 회갑 | 1일 |

1. 경조사 휴가는 해당 사유 발생일로부터 30일 이내에 사용하여야 한다.
2. 휴가일수는 근무일 기준으로 산정하며, 토·일요일 및 공휴일은 산입하지 아니한다.

### 제11조 (리프레시 휴가)

1. **근속 5년마다 10일의 리프레시 휴가**를 부여한다.
2. 리프레시 휴가는 해당 근속연수 도달일이 속한 연도부터 **2년 이내**에 사용하여야 하며,
   기간 내 미사용 시 소멸한다.
3. 리프레시 휴가는 **연속하여 사용함을 원칙**으로 하되, 최대 2회로 분할할 수 있다.
4. 리프레시 휴가 사용자에게는 제13조의 장기근속 포상금과 별도로
   **휴가 지원금 50만원**을 지급한다.

# 제4장 복리후생

### 제12조 (하계휴가 지원금)

1. 하계휴가 사용을 지원하기 위하여 매년 7월 급여 지급일에 하계휴가 지원금을 지급한다.
2. 지원금은 근속연수에 따라 다음과 같이 차등 지급한다.

   | 근속연수 | 지원금 |
   |---|---|
   | 3년 이상 | **400,000원** |
   | 1년 이상 3년 미만 | **250,000원** |
   | 1년 미만 | **150,000원** |

3. 지원금 지급 기준일은 **매년 6월 30일**이며, 해당일 기준 재직 중인 자에게 지급한다.
4. 계약직 직원 중 계약기간이 1년 이상인 자에게도 동일하게 적용한다.

### 제13조 (장기근속 포상)

1. 근속연수 도달 시 다음과 같이 포상금과 특별휴가를 부여한다.

   | 근속연수 | 포상금 | 특별휴가 |
   |---|---|---|
   | 5년 | 1,000,000원 | 3일 |
   | 10년 | 2,000,000원 | 5일 |
   | 15년 | 3,000,000원 | 7일 |
   | 20년 | 5,000,000원 | 10일 |
   | 25년 | 7,000,000원 | 10일 |
   | 30년 | 10,000,000원 | 15일 |

2. 포상은 매년 **창립기념일(3월 15일)** 행사에서 일괄 시상한다.
3. 특별휴가는 시상일로부터 1년 이내에 사용하여야 한다.

### 제14조 (경조사비)

| 구분 | 대상 | 금액 | 화환·조화 |
|---|---|---|---|
| 결혼 | 본인 | 500,000원 | 화환 1개 |
| | 자녀 | 300,000원 | 화환 1개 |
| 출산 | 첫째 | 300,000원 | — |
| | 둘째 | 500,000원 | — |
| | 셋째 이상 | 1,000,000원 | — |
| 사망 | 배우자, 본인 및 배우자의 부모 | 500,000원 | 조화 1개 |
| | 본인 및 배우자의 조부모, 형제자매 | 200,000원 | 조화 1개 |
| | 자녀 | 500,000원 | 조화 1개 |

1. 경조사비는 사유 발생일로부터 **60일 이내에 신청**하여야 하며, 증빙서류를 첨부한다.
2. 부부가 모두 회사에 재직 중인 경우 1인에게만 지급한다.

### 제15조 (자기계발 지원)

1. 직무와 관련된 외부 교육 수강료를 **연 2,000,000원 한도**에서 지원한다.
2. 지원 절차는 다음과 같다.
   - 수강 시작 **7일 전까지** 사전 신청 및 팀장 승인
   - 수료 후 **30일 이내**에 수료증과 영수증 제출
3. **수료증을 제출한 경우 수강료의 100%를, 제출하지 못한 경우 지원하지 아니한다.**
4. 지원받은 교육의 수료일로부터 1년 이내에 자발적으로 퇴사하는 경우
   지원금 전액을 반환하여야 한다.
5. 공인 어학시험 응시료는 **연 4회까지** 실비를 지원하며, 제1항의 한도에 산입하지 아니한다.

### 제16조 (건강검진)

1. 전 임직원은 매년 1회 일반 건강검진을 받는다.
2. **만 35세 이상인 자는 2년마다 종합 건강검진**을 받을 수 있으며, 비용은 회사가 부담한다.
3. 종합 건강검진 대상자의 **배우자 1인**에 대하여 검진 비용의 50%를 지원한다.
4. 검진일은 유급 공가로 처리한다.

### 제17조 (기타 지원)

| 항목 | 내용 |
|---|---|
| 중식 | 구내식당 무료 (외부 식사 시 1일 9,000원 한도 지원) |
| 통근버스 | 포항·경주·울산 3개 노선 무료 운행 |
| 사내 동호회 | 5인 이상 등록 동호회에 연 1,200,000원 지원 |
| 자녀 학자금 | 고등학생 연 2,000,000원, 대학생 연 4,000,000원 (2자녀까지) |
| 주택자금 대출 | 근속 3년 이상, 최대 50,000,000원 (연 1.5%) |

# 제5장 출장

### 제18조 (국내 출장)

1. 국내 출장 시 다음 기준으로 비용을 지급한다.

   | 구분 | 지급 기준 |
   |---|---|
   | 일비(식대 포함) | **1일 30,000원** |
   | 숙박비 | 실비, **1박 100,000원 한도** (서울·경기 130,000원) |
   | 교통비 | 실비 (KTX 일반실, 항공 이코노미) |

2. 당일 출장으로서 왕복 4시간 미만인 경우 일비의 50%를 지급한다.
3. 회사 차량을 이용하는 경우 유류비와 통행료는 별도 실비 정산한다.

### 제19조 (해외 출장)

1. 해외 출장 일비는 지역 등급에 따라 다음과 같이 지급한다.

   | 등급 | 해당 지역 | 1일 일비 |
   |---|---|---|
   | A | 미국, 서유럽, 일본, 싱가포르 | USD 90 |
   | B | 중국, 동유럽, 중동 | USD 70 |
   | C | 동남아시아, 중남미, 기타 | USD 55 |

2. 숙박비는 등급별 한도 내 실비로 정산하며, 세부 한도는 인사총무팀 공지에 따른다.
3. 해외 출장자는 출발 **14일 전까지** 출장계획서를 제출하여야 한다.

### 제20조 (출장 신청 절차)

1. 국내 출장은 **출발 3근무일 전까지**, 해외 출장은 **출발 14일 전까지** 신청한다.
2. **차량 배차 신청은 출발 3일 전까지** 완료하여야 한다.
3. 출장 복귀 후 **5근무일 이내**에 출장보고서와 비용 정산서를 제출한다.
4. 기한 내 정산서를 제출하지 아니한 경우 익월 급여에서 가지급금을 공제한다.

# 제6장 교육

### 제21조 (직무교육)

1. 전 임직원은 **연간 40시간 이상**의 직무교육을 이수하여야 한다.
2. 이수 시간은 사내 교육, 외부 교육, 온라인 과정을 합산하여 산정한다.
3. 미이수자는 익년도 1분기 내에 보충 이수하여야 한다.

### 제22조 (AI 활용 역량 교육)

1. 2026년부터 전 임직원은 **연간 8시간의 AI 활용 교육을 필수**로 이수한다.
2. 교육 과정은 다음 3개 과정으로 구성한다.

   | 과정 | 대상 | 시간 |
   |---|---|---|
   | AI 기초 활용 | 전 직원 | 4시간 |
   | AI Agent 개발 입문 | 희망자 | 16시간 |
   | 업무 자동화 심화 | 수료자 중 선발 | 24시간 |

3. 「AI Agent 개발 입문」 과정 수료자에게는 직무교육 이수시간 16시간을 인정한다.
4. 교육 중 생성한 산출물은 사내 업무에 한하여 활용할 수 있으며,
   대외비 자료를 외부 AI 서비스에 입력하는 것을 금지한다.
