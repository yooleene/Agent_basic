## 이 실습에서 할 일

막연한 아이디어 한 줄을 주면, **AI가 나에게 질문**을 던지며 아이디어를 구체화해 줍니다.

## 진행 순서

### STEP 1 · 스킬 설치

Cursor Agent 채팅에 링크를 주고 `이 스킬 설치해줘`

### STEP 2 · 아이디어 입력

```
/grill-me 냉장고 재료 입력하면 만들 수 있는 요리 추천하는 앱 만들고 싶어
```

### STEP 3 · 질문에 답하기

누가 쓰는지, 어떤 문제인지, 가장 중요한 기능 하나, MVP 범위, 성공 기준… 질문에 차례로 답합니다.
질문이 한꺼번에 나오면 `1번부터 하나씩 물어봐 줘` 라고 하세요.

### STEP 4 · 결과 확인

문제 정의 / 대상 사용자 / 핵심 가치 / MVP 범위 / 성공 기준이 정리된 검증 결과를 확인합니다.
