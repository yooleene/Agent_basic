# 실습 1 · General RAG 구현

**50분** · 개인 실습

---

## 오늘 만들 것

PDF를 올리면 벡터DB를 만들고, 질문하면 관련 조각(chunk)을 찾아 답하는 **ChatGPT 스타일 웹 챗봇**을 만듭니다.

| 항목 | 설정 |
|---|---|
| 문서 로딩 | `PyPDFLoader` |
| 청킹 | `RecursiveCharacterTextSplitter` · 500자 분할 / 100자 오버랩 |
| 임베딩 | `text-embedding-3-small` |
| 벡터DB | ChromaDB |
| 검색 | 유사 chunk 상위 4개 |
| LLM | `gpt-4o-mini` |
| 기타 | 대화 메모리, 참고 chunk·페이지 출력, 정보가 없으면 "정보가 없어서 답변할 수 없습니다" |

> 7번 시간 실습 ③에서 배운 네 단어 — **청킹 · 임베딩 · 벡터DB · 검색** — 을 이제 Cursor에게 직접 시킵니다.

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `2022년 버전 선재 카탈로그_국문_최종.pdf` | 업로드 테스트용 문서 |
| `붙여넣기용_프롬프트.md` | Cursor에 붙여넣을 프롬프트 |

## 진행 순서

### STEP 1 · 개발 환경 준비 (5분)

1. 탐색기로 **이 폴더(`M3_08-1_general_rag`)** 로 이동 → 주소창에 `cmd` 입력 → 엔터
2. 터미널에 아래 명령 입력

```
pip list > requirements.txt
```

> 내 PC에 설치된 패키지와 버전을 Cursor가 알게 하려고 만드는 파일입니다.
> 이 파일이 없으면 Cursor가 버전이 안 맞는 코드를 짜서 에러가 나기 쉽습니다.

3. Cursor에서 **File → Open Folder → `M3_08-1_general_rag`** 폴더를 엽니다.

### STEP 2 · 프롬프트 입력 (10분)

`붙여넣기용_프롬프트.md` 를 엽니다.

- **프롬프트 1** — 요구사항을 한 줄씩 적은 초안
- **프롬프트 2** — 초안을 목표 / 기술 스펙 / 제약조건 & 완료 기준으로 정리한 버전

**프롬프트 2를 통째로 복사**해 Cursor 채팅(Agent 모드)에 붙여넣으세요.
폴더 생성·패키지 설치 승인 요청이 나오면 **승인**합니다.

> 프롬프트 1과 2를 비교해 보세요. 내용은 같은데 **완료 기준**이 추가되었습니다.
> AI는 "언제 끝난 것인지"를 알 때 더 끝까지 만듭니다.

### STEP 3 · 실행 (5분)

코딩이 끝나면 터미널에서

```
python app.py
```

터미널에 뜬 주소(`http://127.0.0.1:5000` 등)를 **Ctrl + 클릭**합니다.

### STEP 4 · 동작 테스트 (15분)

`2022년 버전 선재 카탈로그_국문_최종.pdf` 를 업로드한 뒤 질문해 보세요.

- [ ] 카탈로그에 있는 내용을 물었을 때 답변 + **참고 chunk와 페이지 번호**가 나오는가
- [ ] 페이지 번호를 PDF에서 직접 찾아 **맞는지** 확인했는가
- [ ] 카탈로그와 무관한 질문(예: "오늘 날씨는?")에 **"정보가 없어서 답변할 수 없습니다"** 라고만 답하는가
- [ ] "방금 말한 제품의 용도는?" 처럼 **앞 대화를 이어받는 질문**이 되는가
- [ ] PDF가 아닌 파일은 업로드가 막히는가

### STEP 5 · 에러 수정 (10분)

에러가 나거나 화면이 이상하면 9번 시간의 **STOP · COPY · TELL** 그대로 합니다.

1. 에러 화면을 **캡처**하거나 터미널 에러를 **통째로 복사**
2. Cursor 채팅에 붙여넣고 **무엇을 하다가 어떻게 됐는지** 한 줄 설명
3. 수정이 끝나면 **웹페이지를 새로고침**해서 확인

## 잘 안 될 때

| 증상 | 이렇게 말하세요 |
|---|---|
| 이미 설치된 패키지를 업데이트·재설치하려 한다 (`-U`, `--upgrade`, 다른 버전 지정) | 승인하지 말고 **거절**한 뒤 `이미 설치된 패키지는 업데이트하지 말고 설치된 버전을 그대로 써줘` |
| `ModuleNotFoundError` | `requirements.txt 에 있는 패키지와 버전만 써서 다시 고쳐줘` |
| API 키를 넣으라고 한다 | `키는 코드에 적지 말고 환경 변수 OPENAI_API_KEY에서 읽어줘` |
| 문서에 없는 내용도 지어서 답한다 | `검색된 chunk가 없거나 관련 없으면 "정보가 없어서 답변할 수 없습니다"라고만 답하게 고쳐줘` |
| 페이지 번호가 안 나온다 | `metadata의 page 값을 답변 하단에 함께 표시해줘` |
| 같은 PDF를 두 번 올리면 답이 중복된다 | `같은 파일을 다시 올리면 기존 벡터를 지우고 새로 저장하게 해줘` |

## 완료 기준

- 폴더에 `app.py` 와 Chroma DB 폴더가 생겼다
- 업로드 → 질문 → 답변 + 참고 chunk·페이지 출력까지 확인했다
- 문서에 없는 질문에 지정된 문구로만 답하는 것을 확인했다
