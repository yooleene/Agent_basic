## 프롬프트 1 — 초안 (참고용)

요구사항을 생각나는 대로 한 줄씩 적은 버전입니다.

```
파이썬 langchain 패키지를 이용해서 rag를 만들어줘
- 로컬 PC에 설치된 파이썬 패키지와 패키지 버전은 현재 폴더의 requirements.txt를 참고해 줘.
- flask 패키지를 이용해 웹페이지를 만들어줘
- user interface는 chatgpt와 유사하게 만들어줘
- 버튼, 창 스타일은 연한 청색, 회색 컬러로 산뜻하게 만들어줘
- 왼쪽 메뉴창 상단에 파일 업로드 버튼표시 (여러개 파일 업로드)
- pdf 파일만 업로드 할꺼야
- llm은 gpt-4o-mini 모델을 사용해야해. api-key는 나의 시스템 환경에 있으니 설정 안해도 돼
- 이파일을 PyPDFLoader 로 로딩해줘
- RecursiveCharacterTextSplitter로 500글자 분할, 100글자 오버랩
- text-embedding-3-small로 임베딩하고 chromadb에 저장
- 사용자가 질문을 할때 유사한 chunk를 4개까지 검색해줘
- 답변 출력 후, 참고한 chunk 내용 및 페이지번호를 요약하여 출력해줘
- chunk가 검색되지 않으면 "정보가 없어서 답변할 수 없습니다" 라고 대답해야해
- 대화 메모리 기능을 사용해줘

[패키지 설치 규칙]
- requirements.txt 를 만들 때는 먼저 pip freeze 로 이 PC에 이미 설치된 패키지와 버전을 확인해.
- 이미 설치된 패키지는 설치된 버전을 그대로 적고(예: Flask==3.0.2), 업데이트하거나 다시 설치하지 마. 코드도 설치된 버전에 맞춰 작성해.
- 설치되어 있지 않은 패키지만 새로 설치하고, 설치할 때 -U(--upgrade) 옵션은 쓰지 마.
- 새 패키지를 설치하면서 이미 설치된 패키지의 버전이 바뀌게 되면, 설치하지 말고 나에게 먼저 알려줘.
```

## 프롬프트 2 — 구조화 버전 ⭐ (이것을 붙여넣으세요)

```
# RAG 기반 Flask 웹앱 개발 프롬프트

## 1. 목표
- 이 프로젝트는 PDF 문서를 업로드하고, 문서 내용을 기반으로 질의응답이 가능한 **RAG 기반 웹 챗봇**을 만드는 것이다.
- 사용자 시나리오: ① 왼쪽 메뉴창에서 PDF 파일 업로드(다중 업로드 가능) → ② 채팅창에서 질문 입력 → ③ 답변 + 참고한 chunk 내용과 페이지 번호 확인
- UI/UX는 ChatGPT와 유사한 형태(왼쪽 사이드바 + 오른쪽 채팅 영역)로 구성한다.

## 2. 기술 스펙

### 환경 및 프레임워크
- Python 패키지: LangChain 사용
- 로컬 환경에 설치된 패키지 및 버전은 현재 폴더의 `requirements.txt`파일에 있으며, 반드시 여기에 있는 패키지 및 버전만 사용할 것.
- 웹 프레임워크: Flask
- LLM: `gpt-4o-mini` (API Key는 시스템 환경변수에 설정되어 있으므로 코드 내 별도 설정 불필요)

### RAG 파이프라인
- 문서 로딩: `PyPDFLoader`
- 청킹: `RecursiveCharacterTextSplitter` (chunk size 500자, overlap 100자)
    - 분할 기준(separators)은 "문단 → 문장" 순으로 우선 적용
    - 예: `separators=["\n\n", "\n", ". ", "? ", "! ", " ", ""]`
    - 문단 구분(빈 줄, 줄바꿈)을 최우선으로 분할하고, 문단 내에서는 문장 단위(마침표, 물음표, 느낌표 뒤)로 분할되도록 구성
- 임베딩: `text-embedding-3-small`
- 벡터 DB: ChromaDB
- 검색: 질문 시 유사도 기준 상위 4개 chunk 검색
- 대화 메모리 기능 포함 (이전 대화 맥락 유지)

### UI 상세
- 왼쪽 메뉴창: 상단에 파일 업로드 버튼 배치 (PDF 다중 업로드 지원)
- 색상 톤: 연한 청색 + 회색 계열, 산뜻하고 깔끔한 느낌
- 채팅창: ChatGPT 스타일의 대화형 인터페이스

### 응답 형식
- 답변 출력 후, 답변 하단에 참고한 chunk 내용 요약 및 페이지 번호를 함께 표시

## 3. 제약조건 & 완료 기준

### 제약조건
- 업로드 가능한 파일 형식은 PDF만 허용 (다른 형식은 업로드 제한 또는 오류 처리)
- 검색된 관련 chunk가 없을 경우, 반드시 "정보가 없어서 답변할 수 없습니다"라고만 응답 (임의로 답변 생성 금지)

### 완료 기준 (Definition of Done)
1. PDF 여러 개를 업로드하면 정상적으로 벡터 DB에 저장된다.
2. 질문 시 관련 chunk 4개를 검색하여 답변에 반영한다.
3. 답변과 함께 참고 chunk 요약 + 페이지 번호가 함께 출력된다.
4. 관련 정보가 없을 경우 지정된 문구로만 응답한다.
5. 이전 대화 맥락을 반영한 대화가 가능하다.

## 4. 패키지 설치 규칙
- requirements.txt 를 만들 때는 먼저 pip freeze 로 이 PC에 이미 설치된 패키지와 버전을 확인해.
- 이미 설치된 패키지는 설치된 버전을 그대로 적고(예: Flask==3.0.2), 업데이트하거나 다시 설치하지 마. 코드도 설치된 버전에 맞춰 작성해.
- 설치되어 있지 않은 패키지만 새로 설치하고, 설치할 때 -U(--upgrade) 옵션은 쓰지 마.
- 새 패키지를 설치하면서 이미 설치된 패키지의 버전이 바뀌게 되면, 설치하지 말고 나에게 먼저 알려줘.
```
