# md 파일 작성 (SDD)

**6. 바이브코딩 스킬 활용** · 개인 실습

---

## 이 실습에서 할 일

"오늘의 할일" 앱의 설계 문서 **`ui.md` · `architecture.md` · `prompts.md`** 3개를 AI에게 먼저 쓰게 합니다.
코드보다 **스펙(문서)을 먼저** 만드는 방식(Spec-Driven Development)입니다.

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `붙여넣기용_프롬프트.md` | 복사해서 쓸 프롬프트·코드 |

---

## 진행 순서

### STEP 1 · Cursor Chat 열기

이 폴더를 Cursor로 열고 **Ctrl+L** 로 채팅을 엽니다.

### STEP 2 · 프롬프트 입력

`붙여넣기용_프롬프트.md` 의 프롬프트를 붙여넣습니다.

### STEP 3 · 파일로 저장

결과가 채팅에만 나오면 `3개 내용을 각각 파일로 저장해줘` 라고 요청합니다.

```
todo-app/
 ├ ui.md
 ├ architecture.md
 └ prompts.md
```

### STEP 4 · 검토

세 파일을 열어 보고, 내가 원하는 색상·기능과 다른 부분을 직접 고칩니다.

---

## 완료 기준

- md 파일 3개가 폴더에 생겼다
- 각 파일에 무엇이 들어 있는지 설명할 수 있다
