# 버그 ② AI 번역기

## 이 프로그램이 하는 일

`config.py`에 적어 둔 문장을 OpenAI API로 번역해서 화면에 보여줍니다.
설치할 패키지는 없습니다. 파이썬 기본 기능만 씁니다.

## 실행 방법

Cursor에서 **이 폴더를 열고**, 터미널에 아래를 입력합니다.

```
python translate.py
```

## 기대하는 결과

```
원문   : 이번 분기 설비 점검 결과를 정리해서 수요일까지 공유해 주세요.
번역 중 ...
번역문 : Please summarize this quarter's equipment inspection results and share them by Wednesday.

(사용 토큰: 입력 NN / 출력 NN)
```

## 📌 이 노트북의 환경

**여러분의 실습 노트북에는 OpenAI API 키가 환경 변수로 이미 설정되어 있습니다.**
따로 키를 발급받거나 입력할 필요가 없습니다. 이 사실을 기억해 두세요.

## 지금 상태

**"번역 중 ..."까지는 나오는데, 그 다음에 에러가 납니다.**
Cursor를 시켜서 정상 동작하게 만드세요.

> 에러 메시지의 **숫자와 단어를 그대로** Cursor 채팅에 붙여넣고,
> 그 에러가 무슨 뜻이고 어디를 봐야 하는지 물어보세요.
>
> `----- 서버가 보낸 응답 -----` 안에 힌트가 들어 있습니다.

원인을 알아냈다면, 위 **"이 노트북의 환경"**을 다시 읽고
Cursor에게 어떻게 고쳐달라고 할지 생각해 보세요.

**코드는 직접 고치지 않습니다.** 고치는 것은 Cursor가 합니다.

## ⚠️ 보안 주의

- 이 실습에서 **키 값을 직접 보거나 입력할 일은 없습니다.**
- 혹시라도 키 값을 알게 되더라도 **채팅창에 붙여넣지 마세요.**
- 키를 코드에 직접 적어두는 것은 실무에서 하면 안 되는 일입니다.
  오늘 그 이유를 몸으로 겪게 됩니다.

## 완료 기준

- `python translate.py`가 에러 없이 끝난다
- 화면에 번역문이 출력된다
- `config.py`의 `TEXT`를 다른 문장으로 바꿔도 번역이 된다
- **코드 어디에도 키 값이 적혀 있지 않다**
