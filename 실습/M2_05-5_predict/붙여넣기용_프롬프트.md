아래 회색 상자를 **통째로 복사**해서 붙여넣으세요.

## 프롬프트 1 — 요구사항 정리 (ChatGPT 등 LLM 채팅창에 입력)

```
아래 내용을 참고해서 개발환경, 노드(기능), UI로 구분해줘
=====
파일을 업로드하면 변수 변화에 따라 예측하는 시스템을 만들고 싶어

 2. 개요
  - 파이썬을 flask를 활용해서 예측 시스템 코드를 생성해줘
  - 그래프 그릴때 한글이 안깨지도록 설정해줘
  - 파일 업로드 부터 시뮬레이션 단계까지 순차적으로 진행되는데
    전단계의 결과가 다음 단계에서 사용되는거야, 세션이 유지될 수 있도록
    전 단계 결과를 sqlite3에 저장해서 사용해줘

 3. 화면구성
  - user inteface의 컬러는 연한 녹색, 연한 파란색, 회색으로 만들어줘
  - 화면을 2분할하는데 좌측을 20%, 우측을 80% 비율로 만들어줘, 우측 화면을 상단 10%, 하단 90%로 분할해줘
  - 좌측 화면 메뉴 구성은 "1. 파일 업로드", "2. 변수 선택",  "3. 결측치 제거", "4. 이상치 탐색", "5. 탐색적 분석", "6. 회귀분석", "7. 모델 검증", "8. 시뮬레이션" 으로 해줘
  - 좌측 화면 메뉴는 순서대로 진행되어야 하기 때문에 처음에는 "1. 파일 업로드"를 진하게 표시하고 나머지 메뉴는 연하게 표시해줘,
    하나의 메뉴가 실행된 후 다음 메뉴를 진하게 표시해줘
  - 우측 화면 상단은, 좌측 메뉴를 눌렸을때 단계(예시 : 2. 변수선택)등이 표시되고 우측 하단 화면은 서브메뉴와 실행 결과가 나와야해

4. 메뉴별 구성
  - "1. 파일 업로드" 메뉴를 클릭하면 폴더에서 csv, excel 파일을 업로드 할 수 있게 해줘,
    파일을 업로드 하면 우측화면 하단에 pandas 패키지를 이용해서 10개의 행만 출력
    해줘, 그리고 각 변수의 기초 통계량을 출력해줘

  - "2. 변수 선택" 메뉴를 클릭하면 우측 화면 상단에 종속변수와 독립변수를 선택하는 
    메뉴 만들어줘, 사용자가 변수를 선택하면 그것을 기준으로 차후 분석을 진행해야해

  - "3. 결측치" 제거 메뉴를 클릭하면 결측치가 있는 행을 찾고 제거해줘,
    결과 값으로 총 몇개의 행이 있었고, 결측치 행을 몇개 제거했는지, 현재 몇개행이
    남아 있는지 표시해줘

  - "4. 이상치 탐색" 메뉴를 클릭하면 각 변수별  +,- 3 표준편차 범위 밖에 존재하는
    데이터가 몇개나 있는지 표시해줘, 그리고 변수별 이상치 행을 제거해야 하는지 우측
    화면 상단에서 선택할 수 있도록 표시해줘, 사용자가 이상치 제거를 선택하면
    이상치 행을 제거해줘

  - "5. 탐색적 분석" 메뉴를 클릭하면 우측화면 상단에 "히스토그램" , "산점도",
    "상관관계(히트맵)" 분석 메뉴를 표시해줘, "히스토그램"을 선택하면 사용자가 변수를 
    선택할 수 있도록 하고, 변수 선택 후 히스토그램과 밀도 곡선을 겹쳐서 그려줘,
    "산점도"를 선택하면 여러개의 변수를 선택하게 하고, 변수 선택 후 산점도를 그려줘,
    "상관관계(히트맵)"을 선택하면 전체 변수의 상과계수가 표시된 히트맵을 그려줘

  - "6. 회귀분석" 메뉴를 클릭하면 우측 상단 화면에 "전진선택법", "후진제거법", "릿지", 
    "라쏘" 메뉴가 보이게 해줘,
    사용자가 선택한 메뉴로 회귀분석을 실시하고, 회귀모형과, 예측 정확도를 출력해줘,
    사용자가 모델의 결과값을 보고 최종 모델을 선택할 수 있도록 해줘
 
  - "7. 모델검증"을 클릭하면 잔차분석과 적합도검정을 진행하고 결과를 보여줘

  - "8. 시뮬레이션"을 클릭하면 만들어진 회귀모형을 시뮬레이션 할 수 있도록 해줘
    우측화면의 상단에는 사용자가 선택한 회귀식을 출력해줘
    인터랙티브한 그래프 출력을 위해 Plotly, Dash 패키지를 사용해줘
    우측화면의 화단에는 회귀모형의 독립변수를 슬라이더바로 입력할 수 있게 하고
    아래쪽에는 종속변수의 값과 막대그래프로 크기 변화를 출력해줘
    가독성있게 한 화면에서 슬라이더바 입력, 종속변수 값이 출력되어야 해
  
 5. 기타
  - 추가로 필요한 기능이 있다면 나한테 물어보고 추가해줘
  - 웹 시스템은 한글로 구현해줘
```

## 프롬프트 2 — Cursor용 프롬프트 만들기 (LLM에 입력 → 나온 결과를 Cursor에 붙여넣기)

```
커서로 예측 시스템을 만들건데, 아래 내용을 커서에 넣을 프롬프트로 작성해줘
파이썬 Flask를 활용한 예측 시스템을 개발하고 싶어
1. 개발환경
  - Flask 패키지 사용
  - 데이터 처리: pandas 패키지
  - 그래프: matplotlib (한글 깨짐 방지 설정), Plotly, Dash
  - 세션 관리: SQLite3 (단계별 결과 저장, 전 단계 결과를 다음 단계에서 사용)
  - 파일 업로드: csv, excel 지원
  - 전체 시스템 한글로 구현

2. 노드설명
  - 파일 업로드부터 시뮬레이션까지 순차적으로 진행
  - 각 단계의 결과는 SQLite3에 저장되며, 다음 단계에서 이전 결과를 불러와 사용
  - 파일 업로드: csv, excel 업로드 후 pandas로 10개 행 출력 및 기초 통계량 출력
  - 변수 선택: 종속변수 및 독립변수 선택, 이후 분석에 적용
  - 결측치 제거: 결측치 행 탐색 및 제거, 총 행 수 / 제거 행 수 / 잔여 행 수 출력
  - 이상치 탐색:
    · 변수별 ±3 표준편차 범위 밖 데이터 탐색
    · 변수별 이상치 제거 여부 선택 및 제거
  - 탐색적 분석:
    · 히스토그램: 변수 선택 후 히스토그램 + 밀도 곡선 출력
    · 산점도: 다중 변수 선택 후 산점도 출력
    · 상관관계(히트맵): 전체 변수 상관계수 히트맵 출력
    - 회귀분석:
    · 전진선택법 / 후진제거법 / 릿지 / 라쏘 선택
    ·  회귀모형 및 예측 정확도 출력, 최종 모델 선택
  - 모델 검증: 잔차분석 및 적합도 검정 결과 출력
  - 시뮬레이션: 선택된 회귀모형으로 시뮬레이션, 독립변수 슬라이더바 입력, 종속변수 값 및 막대그래프 출력
  - 단계별 순차 진행 (전 단계 완료 후 다음 단계 활성화)
  - 추가 기능 필요 시 사용자에게 확인 후 추가

3. UI설명
  - 컬러: 연한 녹색, 연한 파란색, 회색- 화면 2분할: 좌측 20% / 우측 80%
  - 우측 화면: 상단 10% (현재 단계 표시) / 하단 90% (서브메뉴 및 실행 결과)
  - 좌측 메뉴 구성: 1.파일업로드 / 2.변수선택 / 3.결측치제거 / 4.이상치탐색 / 5.탐색적분석 / 6.회귀분석 / 7.모델검증 / 8.시뮬레이션
  - 좌측 메뉴: 현재 단계 진하게, 나머지 연하게 표시, 단계 완료 시 다음 메뉴 활성화
  - 우측 상단: 현재 메뉴 단계명 표시
  - 우측 하단: 서브메뉴 및 실행 결과 표시
  - 탐색적 분석 서브메뉴: 히스토그램 / 산점도 / 상관관계(히트맵) 탭
  - 회귀분석 서브메뉴: 전진선택법 / 후진제거법 / 릿지 / 라쏘 탭
  - 시뮬레이션: 회귀식 출력, 슬라이더바 입력, 종속변수 값 및 막대그래프 한 화면 구성 (Plotly/Dash)
```

## 패키지 설치 규칙 — Cursor에 붙여넣을 때 프롬프트 맨 끝에 함께 붙여넣으세요

이 PC에 이미 설치된 패키지를 그대로 쓰게 하는 규칙입니다.

```

[패키지 설치 규칙]
- requirements.txt 를 만들 때는 먼저 pip freeze 로 이 PC에 이미 설치된 패키지와 버전을 확인해.
- 이미 설치된 패키지는 설치된 버전을 그대로 적고(예: Flask==3.0.2), 업데이트하거나 다시 설치하지 마. 코드도 설치된 버전에 맞춰 작성해.
- 설치되어 있지 않은 패키지만 새로 설치하고, 설치할 때 -U(--upgrade) 옵션은 쓰지 마.
- 새 패키지를 설치하면서 이미 설치된 패키지의 버전이 바뀌게 되면, 설치하지 말고 나에게 먼저 알려줘.
```
