# Skill 활용 방법

**6. 바이브코딩 스킬 활용** · 개인 실습

---

## 이 실습에서 할 일

Skill 검색 사이트에서 필요한 스킬을 찾아 **설치 → `/` 로 호출 → 결과 생성** 순서를 익힙니다.

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `붙여넣기용_프롬프트.md` | 복사해서 쓸 프롬프트·코드 |

---

## 진행 순서

### STEP 1 · 스킬 검색

링크 두 곳에 접속해 `pdf`, `frontend-design`, `grill-me` 등을 검색해 봅니다.

### STEP 2 · 스킬 설치

Cursor **Agent 모드** 채팅에 스킬 페이지 URL을 주고 `이 스킬 설치해줘` 라고 요청합니다.
Agent가 `npx skills add owner/repo` 를 대신 실행합니다.

### STEP 3 · 스킬 호출

채팅창에 `/` 를 입력하면 설치된 스킬 목록이 나옵니다. 예) `/frontend-design` 입력 후 프롬프트 작성

---

## 완료 기준

- 스킬 1개 이상 설치하고 `/` 로 호출해 봤다
