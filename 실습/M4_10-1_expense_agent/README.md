# 출장비 정산 검토 에이전트 만들기

**M4 · 10. AI Agent 맛보기** · 개인 실습 · **약 65분**

---

## 오늘 만들 것

인사총무팀 담당자가 되어, **출장비 정산서 8건을 사내 규정에 따라 검토하는 에이전트**를 만듭니다.

```
[정산서 한 건씩]  사실 확인 → 검토 절차 찾기 → 규정에서 근거 찾기 → 계산·날짜는 도구로 → 판정·저장
[8건이 끝나면]    검수 → 실패한 건만 다시 검토 → 그래도 안 되면 사람에게 넘김
```

| 판정 | 언제 |
|---|---|
| 승인 | 모든 항목이 기준 충족 |
| 감액 승인 | 한도 초과분을 빼고 지급 |
| 보완 요청 | 영수증 누락 등 서류 미비 → 메일 초안 작성 |
| 사람 확인 필요 | 규정에 없는 비용, 신청자 특정 불가 → **AI가 판단하지 않고 넘김** |

**한 번 물어보고 끝나는 챗봇과의 차이**는 여기서 보입니다.
정산서마다 내용이 달라서, 에이전트가 찾는 규정과 부르는 도구도 달라집니다.
**일을 한 건씩 나눠 주는 것은 사람(파이썬)**, **각 건에서 무엇을 확인하고 어떻게 판정할지는 AI**가 정합니다.

> 에이전트의 판정이 정답과 다를 수도 있습니다. 그것을 찾아내는 것이 STEP 4의 활동입니다.

## 진행 순서

### STEP 1 · 사람이 먼저 판정해 보기 (10분)

Cursor에서 **이 폴더를 엽니다.** `출장비_정산_세부지침.md` 를 훑어본 뒤,
정산서 3건을 골라 직접 판정해 보세요. (나중에 에이전트와 비교합니다)

| 번호 | 내 판정 | 승인금액 | 근거 조항 | 에이전트 판정 | 같은가? |
|---|---|---|---|---|---|
| C__ | | | | | |
| C__ | | | | | |
| C__ | | | | | |

> 💡 **C04** 와 **C05** 는 꼭 한 번 보세요. 제출일이 마감일 전인지, 달력만 보고 판단할 수 있나요?
> 9월 말에는 무엇이 있었죠?

### STEP 2 · 요구사항서 넣기 (15분)

`요구사항서.txt` 의 복사 구간을 **통째로** Cursor 채팅(**Agent 모드**)에 붙여넣습니다.
`agent.py` 가 만들어질 때까지 기다립니다. (5~10분) 승인 요청이 나오면 승인합니다.
Cursor는 실행까지 하지 않고 멈춥니다. 실행은 STEP 3에서 직접 합니다.

> ⚠️ 길다고 일부만 복사하면 에이전트가 안 만들어집니다.

요구사항서를 읽으며 **눈여겨볼 곳 세 군데**:

- **[전체 흐름]** — 파이썬은 '한 건씩 넘겨주기'만 합니다. 왜 8건을 한 번에 맡기지 않을까?
- **[판단은 AI가 한다]** — 건 안에서 순서를 코드에 박지 말라는 이유는?
- **[AI에게 주는 진행 방법]** — 검토 절차는 왜 코드가 아니라 **세부지침 문서(제9조)**에 있을까?

### STEP 3 · 실행하고 지켜보기 (15분)

```
python agent.py
```

브라우저에 카드가 쌓입니다. (5~10분 걸립니다. 화면이 안 뜨면 터미널을 보세요)

```
🧭 계획   ── C04 검토 시작 (4/8) ──
🧰 도구   정산서_요약("C04")          → 당일출장: true, 왕복 3시간
🧰 도구   규정_검색("검토 절차")
🧰 도구   규정_검색("당일 출장 일비")
🧰 도구   정산기한_확인("2026-09-22", "2026-09-30")
🧰 도구   계산(["30000*0.5", "15000+24000"])
💾 저장   C04 → 감액 승인 / 39,000원
...
🔍 검수   ❌ 실패 — C07: 보완 요청 메일이 없음
🧭 계획   ── C07 다시 검토 ──
🔍 검수   ✅ 통과
✅ 완료   8건 검토 완료 — 승인 4건, 감액 승인 2건, …
```

체크하며 보세요.

- [ ] 건마다 **검색한 키워드**가 달랐나요? (예: C04는 '당일', C06은 '해외')
- [ ] `임직원_조회` 를 부른 건 **몇 번 정산서**였나요? ____
- [ ] 한 건을 처리하는 데 **몇 단계**가 걸렸나요? 가장 오래 걸린 건은? ____
- [ ] **빨간 카드**(검수 실패 · 넘김)가 있었나요? 그 다음에 무엇을 했나요?

> 건마다 확인하는 규정과 도구가 다르다면, 그것이 여러분이 만든 프로그램이 **에이전트**라는 증거입니다.

### STEP 4 · 결과 검수 — 에이전트가 맞았나? (15분)

`검토결과.md` 를 열어 STEP 1의 내 판정과 비교합니다. 그리고 아래를 확인하세요.

- [ ] C02 서울 숙박 125,000원 — 서울·경기 한도를 적용했는가
- [ ] C04 — 9/30 제출을 **기한 내**로 봤는가 (추석 연휴)
- [ ] C05 — 기한을 넘겼지만 **반려하지 않고**, 비고에 가지급금 공제 대상이라고 적었는가
- [ ] C06 — **출발일** 환율로 환산했는가
- [ ] C07 — `보완요청_메일.md` 에 메일 초안이 생겼는가
- [ ] C08 — 금액을 확정하지 않고 **사람 확인 필요**로 넘겼는가. 사유를 모두 적었는가
- [ ] 모든 건에 **근거 조항**이 있고, 그 조항이 실제로 맞는가
- [ ] 원본 파일(정산서·규정·명부)이 그대로인가 / `agent.py` 에 API 키가 없는가

틀린 건이 있다면 **왜 틀렸는지** 화면 카드에서 찾아보세요.
도구를 안 부르고 머릿속으로 계산했나요? 규정을 안 찾고 추측했나요?

> **검수를 통과했다고 다 맞은 것이 아닙니다.**
> 결과_검수는 형식(판정 종류·근거·금액 일관성·메일)만 봅니다. 판정이 맞는지는 사람이 봐야 합니다.

### STEP 5 · 규정을 바꾸면 판정이 바뀔까? (10분)

1. `출장비_정산_세부지침.md` 를 **복사해 백업**해 둡니다.
2. 세부지침 제3조에 한 줄 추가: `3. 서울·경기 숙박비 한도는 1박 120,000원으로 한다.`
3. 다시 실행 → **C02 판정이 바뀌는지** 확인합니다. (코드는 한 줄도 안 고쳤습니다)
4. 끝나면 백업으로 **원래대로 되돌립니다.**

> 규칙이 바뀌어도 **문서만 고치면** 에이전트가 따라옵니다. 규정을 코드에 박아넣지 않은 이유입니다.

## 잘 안 될 때

| 증상 | 이렇게 말하세요 |
|---|---|
| 패키지를 설치하라고 한다 | `추가 설치 없이 표준 라이브러리만 써서 다시 만들어줘` |
| 키를 넣으라는 코드가 생겼다 | `키를 코드에 적지 말고 환경 변수 OPENAI_API_KEY에서 읽어줘` |
| API 오류 400 (파라미터) | 에러 전문을 붙여넣고 `이 오류의 원인을 찾아 요청 파라미터를 고쳐줘` |
| 도구를 정해진 순서로만 부른다 | `도구 호출 순서를 코드에 박지 말고, 매 단계 AI가 JSON으로 정하게 해줘` |
| 규정 내용이 코드에 적혀 있다 | `규정 내용을 코드에서 빼고, AI가 규정_검색으로 찾게 고쳐줘` |
| 계산을 도구 없이 한다 | `금액·날짜·환율은 반드시 도구로 계산하라고 시스템 프롬프트를 강화해줘` |
| 검수에서 계속 실패한다 | 화면의 실패 사유를 복사해서 `이 사유로 계속 실패해. 원인을 찾아줘` |
| 한 건에서 계속 맴돈다 | `한 건당 15단계 제한과, 같은 도구·같은 입력 반복 방지가 들어 있는지 확인해줘` |
| **Cursor가 agent.py 를 직접 실행한다** | 채팅창의 **중지(Stop)** 버튼을 누르고 `실행하지 말고 멈춰. 실행은 내가 직접 할게` → 터미널에서 직접 `python agent.py` |
| 빨간 '넘김'(사람 확인 필요)이 많다 | 정상 동작입니다. 강사에게 알리고 STEP 4에서 그 건을 사람이 직접 판정해 보세요 |
| 브라우저 화면이 안 뜬다 | 폴더의 `run_report.html` 을 직접 더블클릭. 안 되면 터미널로 진행 |
| 에러가 났다 | 9번 시간처럼 **STOP · COPY · TELL** — 에러 전문을 통째로 붙여넣기 |
