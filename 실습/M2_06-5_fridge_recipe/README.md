# 실습 예제 — 냉장고 재료로 요리 추천 앱

**6. 바이브코딩 스킬 활용** · 개인 실습

---

## 이 실습에서 할 일

**grill-me → to-spec → 코드 작성**까지 스킬을 이어서 써서 앱 하나를 완성합니다.

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `붙여넣기용_프롬프트.md` | 복사해서 쓸 프롬프트·코드 |

---

## 진행 순서

### STEP 1 · 스킬 준비

grill-me, to-spec 스킬이 설치되어 있는지 확인합니다. (없으면 `M2_06-3_grill_me`, `M2_06-4_to_spec` 폴더 참고)

### STEP 2 · 순서대로 입력

`붙여넣기용_프롬프트.md` 아래쪽 **진행 프롬프트 1~5**를 순서대로 입력합니다.

### STEP 3 · Plan 모드 활용 (선택)

5번 전에 Plan 모드로 바꾸면 AI가 **만들 계획을 먼저** 보여 줍니다. 계획을 검토한 뒤 실행하세요.

### STEP 4 · 실행 & 테스트

앱을 실행해 재료 입력 → 요리 추천이 되는지 확인합니다.

---

## 잘 안 될 때

| 증상 | 이렇게 하세요 |
|---|---|
| 이미 설치된 패키지를 업데이트·재설치하려 한다 (`-U`, `--upgrade`, 다른 버전 지정) | 승인하지 말고 **거절**한 뒤 `이미 설치된 패키지는 업데이트하지 말고 설치된 버전을 그대로 써줘` |
| `ModuleNotFoundError` | `필요한 패키지를 설치해줘` |
| API 키를 넣으라는 코드가 생겼다 | `키는 코드에 적지 말고 환경 변수 OPENAI_API_KEY에서 읽어줘` |
| 화면이 기대와 다르다 | 화면을 캡처해 붙여넣고 `이 부분을 ~처럼 바꿔줘` |
| 같은 에러가 3번 반복된다 | **새 채팅**을 열고 문제를 작게 쪼개서 다시 요청 |
