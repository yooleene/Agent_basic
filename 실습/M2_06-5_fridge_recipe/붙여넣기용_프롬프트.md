# 붙여넣기용 프롬프트 — 실습 예제 — 냉장고 재료로 요리 추천 앱

아래 회색 상자를 **통째로 복사**해서 붙여넣으세요.

---

## 아이디어

```
냉장고에 남은 재료를 입력하면 만들 수 있는 요리를 추천해주는 앱을 만들고 싶어
```

---

## 진행 프롬프트 1~5 (Cursor에 순서대로 입력)

**1.**

```
/grill-me 냉장고의 재료로 만들 수 있는 요리 추천 앱 만들고 싶어
```

**2.**

```
1번부터 질문을 체크할 수 있게 물어봐 줘
```

**3.**

```
/to-spec 지금까지 내용을 SPEC.md파일에 작성해줘
```

**4.**

```
SPEC.md 내용을 검토해서 빠진 내용(데이터 모델, 에러 처리, 화면 구성)을 추가해줘
```

**5.**

```
@SPEC.md 내용으로 코드를 작성해

[패키지 설치 규칙]
- requirements.txt 를 만들 때는 먼저 pip freeze 로 이 PC에 이미 설치된 패키지와 버전을 확인해.
- 이미 설치된 패키지는 설치된 버전을 그대로 적고(예: Flask==3.0.2), 업데이트하거나 다시 설치하지 마. 코드도 설치된 버전에 맞춰 작성해.
- 설치되어 있지 않은 패키지만 새로 설치하고, 설치할 때 -U(--upgrade) 옵션은 쓰지 마.
- 새 패키지를 설치하면서 이미 설치된 패키지의 버전이 바뀌게 되면, 설치하지 말고 나에게 먼저 알려줘.
```
