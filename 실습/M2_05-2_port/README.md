# 포트 변경 — 80번 포트와 IP 주소

**5. 바이브코딩 기반 웹 개발** · 개인 실습

---

## 이 실습에서 할 일

포트를 **80번**으로 바꾸고 `host='0.0.0.0'` 으로 열어, **다른 PC에서도 내 서버에 접속**해 봅니다.

---

## 진행 순서

### STEP 1 · 코드 바꾸기

새 파일 **`app.py`** 에 코드를 붙여넣고 저장 → `python app.py`

### STEP 2 · 주소 없이 접속

브라우저에 `http://localhost` 입력 (80번은 기본 포트라 `:80` 을 안 써도 됩니다)

### STEP 3 · 내 IP 확인

새 터미널에서 `ipconfig` → **IPv4 주소** 확인

### STEP 4 · 옆 사람 PC로 접속

옆 사람 브라우저에서 `http://내IP주소` 로 접속해 봅니다.

---

## 잘 안 될 때

| 증상 | 이렇게 하세요 |
|---|---|
| 80번 포트 사용 중 / 권한 오류 | port를 `8080` 으로 바꾸고 `http://localhost:8080` 으로 접속 |
| 다른 PC에서 접속이 안 된다 | 같은 네트워크인지, Windows 방화벽이 Python을 허용했는지 확인 |

---

## 완료 기준

- `localhost` 로 접속했다
- IP 주소로 다른 PC에서 접속했다 (사내 네트워크·방화벽 정책에 따라 막힐 수 있음)
