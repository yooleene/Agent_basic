# 붙여넣기용 프롬프트 — 포트 변경 — 80번 포트와 IP 주소

아래 회색 상자를 **통째로 복사**해서 붙여넣으세요.

---

## 코드 — app.py

```python
from flask import Flask

app = Flask(__name__)

@app.route('/')
def hello():
    return "80번 포트로 접속하셨습니다!"

if __name__ == '__main__':
    # port 설정을 추가하여 80번 문을 엽니다.
    app.run(host='0.0.0.0', port=80)
```
