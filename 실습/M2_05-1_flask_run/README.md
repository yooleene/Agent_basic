# Flask 실행 — 나의 첫 웹 서버

**5. 바이브코딩 기반 웹 개발** · 개인 실습

---

## 이 실습에서 할 일

파이썬 코드 몇 줄로 **웹 서버**를 띄우고 브라우저로 접속해 봅니다.

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `붙여넣기용_프롬프트.md` | 복사해서 쓸 프롬프트·코드 |

---

## 진행 순서

### STEP 1 · 파일 만들기

Cursor에서 이 폴더를 열고 새 파일 **`app.py`** 에 코드를 붙여넣어 저장합니다.

### STEP 2 · 실행

Cursor 터미널(Ctrl+`)에서

```
pip install flask
python app.py
```

### STEP 3 · 접속

터미널에 뜬 `http://127.0.0.1:5000` 을 **Ctrl + 클릭**합니다.

### STEP 4 · 바꿔 보기

문구를 바꾸고 저장 → 터미널에서 **Ctrl+C** 로 서버를 끄고 다시 `python app.py` → 새로고침.

---

## 완료 기준

- 서버를 껐다 켜는 방법을 알았다
