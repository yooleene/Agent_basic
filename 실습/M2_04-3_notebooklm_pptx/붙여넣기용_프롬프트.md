# 붙여넣기용 프롬프트 — 노트북LM 슬라이드 → 편집 가능한 PPTX 변환 앱

아래 회색 상자를 **통째로 복사**해서 붙여넣으세요.

---

## 프롬프트 1 — 요구사항 정리 (ChatGPT 등 LLM 채팅창에 입력)

```
아래 내용을 참고해서 개발환경, 노드(기능), UI로 구분해줘
=====
구글 노트북 LM으로 작성한 이미지 슬라이드를 편집가능한 PPTX로 변환하는 앱을 만들거야

- 파이썬 PyQt5 패키지를 이용해
- 나에게 없는 패키지는 니가 설치해줘
- ocr 패키지는 EasyOCR을 이용해
- 원본도 16:9 크기고, 만들려고 하는 pptx도 16:9 크기야
- 우선 PDF파일을 읽어오는 메뉴만들고, 저장 파일명 및 경로를 지정하는 메뉴도 만들어줘
- pptx 파일명은 업로드한 pdf파일명과 동일하게 자동 설정해.
- 글꼴은 맑은 고딕과 나눔고딕이 있던데, 나눔스퀘어 Bold체도 추가해.
- 변환을 누르면 슬라이드를 하나씩 읽어서 슬라이드에 있는 텍스트를 OCR로 읽어줘, 텍스트는 한글, 영어 등으로 되어 있어
- 기존 텍스트가 있던 위치의 이미지 글자를 배경과 동일하게 만들어줘(텍스트를 삭제)
- 그 다음 그위치에 추출한 텍스트를 원래 크기 그대로 삽입해줘
- 이미지 등 다른 레이아웃은 절대로 변경하지마,
- 좌표 정밀도: 이미지의 해상도(px)와 PPT의 물리적 크기(inch)는 다르기 때문에 비율 계산(Ratio)이 중요해:
. PPT_Width = 10 inches, PPT_Height = 5.625 inches (16:9 기준)
. 기본 폰트로 나눔고딕, 맑은 고딕, 나눔스퀘어 Bold를 선택하게 해줘
```

## 프롬프트 2 — Cursor용 프롬프트 만들기 (LLM에 입력 → 나온 결과를 Cursor에 붙여넣기)

```
아래 내용을 참고해서 Cursor에 넣을 프롬프트 만들어.
구글 노트북 LM으로 작성한 이미지 슬라이드를 편집가능한 PPTX로 변환하는 앱을 만들어줘
1. 개발환경
  - 파이썬 PyQt5 패키지를 이용
  - 나에게 없는 패키지는 설치
  - OCR 패키지: EasyOCR
  - 원본 16:9, 출력 PPTX도 16:9
  - PPT_Width = 10 inches, PPT_Height = 5.625 inches (16:9 기준)
  - 좌표 정밀도: 이미지 해상도(px)와 PPT 물리적 크기(inch) 비율 계산(Ratio) 적용

2. 노드설명
  - PDF 파일 읽기
  - 저장 파일명 및 경로 지정
  - PPTX 파일명은 업로드한 PDF 파일명과 동일하게 자동 설정
  - 변환 실행 시 슬라이드를 하나씩 읽어서 OCR로 텍스트 추출 (한글, 영어 등)
  - 기존 텍스트가 있던 위치의 이미지 글자를 배경과 동일하게 처리 (텍스트 삭제)
  - 추출한 텍스트를 원래 위치 및 크기 그대로 삽입
  - 이미지 등 다른 레이아웃은 변경하지 않음

3. UI설명
  - PDF 파일 불러오기 메뉴
  - 저장 경로 및 파일명 지정 메뉴
  - 기본 폰트 선택: 나눔고딕, 맑은 고딕, 나눔스퀘어 Bold
  - 변환 실행 버튼
```

## 패키지 설치 규칙 — Cursor에 붙여넣을 때 프롬프트 맨 끝에 함께 붙여넣으세요

이 PC에 이미 설치된 패키지를 그대로 쓰게 하는 규칙입니다.

```

[패키지 설치 규칙]
- requirements.txt 를 만들 때는 먼저 pip freeze 로 이 PC에 이미 설치된 패키지와 버전을 확인해.
- 이미 설치된 패키지는 설치된 버전을 그대로 적고(예: Flask==3.0.2), 업데이트하거나 다시 설치하지 마. 코드도 설치된 버전에 맞춰 작성해.
- 설치되어 있지 않은 패키지만 새로 설치하고, 설치할 때 -U(--upgrade) 옵션은 쓰지 마.
- 새 패키지를 설치하면서 이미 설치된 패키지의 버전이 바뀌게 되면, 설치하지 말고 나에게 먼저 알려줘.
```
