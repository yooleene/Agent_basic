# 버그 ① 회의록 정리기

## 이 프로그램이 하는 일

`meeting_sample.txt`(회의록)를 읽어서 **실행 과제로 보이는 문장만** 골라내고,
화면에 번호를 매겨 보여준 뒤 `실행과제.md` 파일로 저장합니다.

## 실행 방법

Cursor에서 **이 폴더를 열고**, 터미널에 아래를 입력합니다.

```
python app.py
```

## 기대하는 결과

```
======================================================
  주간 팀 회의 - 실행 과제 정리
======================================================
  뽑아낸 실행 과제: 총 6건
------------------------------------------------------
   1. ...
   2. ...
======================================================

  저장 완료 → 실행과제.md
```

## 지금 상태

**실행하면 바로 멈춥니다.** Cursor를 시켜서 정상 동작하게 만드세요.

> 화면의 빨간 글씨를 **텍스트로 통째로 복사**해서 Cursor 채팅에 붙여넣고,
> 무엇이 문제이고 어떻게 해결하면 되는지 물어보세요.
> (스크린샷 말고 반드시 텍스트로!)

**코드는 직접 고치지 않습니다.** 고치는 것은 Cursor가 합니다.
여러분이 할 일은 **상황을 정확히 전달하는 것**뿐입니다.

## 완료 기준

- `python app.py`가 에러 없이 끝난다
- 화면에 실행 과제 목록이 번호와 함께 출력된다
- 폴더에 `실행과제.md` 파일이 새로 생기고, 열면 내용이 들어 있다
