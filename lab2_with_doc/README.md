## 이 문서에 대해

**한빛소재 주식회사는 실재하지 않는 가상의 회사입니다.**
모든 조항과 금액은 AI 교육 실습을 위해 만들어진 허구이며, 실제 사규가 아닙니다.

가상 회사를 쓰는 이유는 두 가지입니다.

1. 실제 사내 문서를 외부 AI 서비스에 올리지 않기 위해서
2. 여러분이 **정답을 문서에서 직접 확인**할 수 있게 하기 위해서

> 확인할 것은 "정답이 맞는가"가 아니라
> **"문서를 주면 AI의 답이 어떻게 달라지는가"** 입니다.

## 진행 순서

### STEP 1 · AI가 보라고 한 문서를 준다 (6분)

실습 ①에서 AI는 **"사내 규정 문서를 확인하세요"**라고 했습니다.
**지금 그 문서를 주는 겁니다.**

실습 ①의 **B-1, B-2 질문을 토씨 하나 바꾸지 말고** 그대로 다시 던지세요.
PDF를 채팅창에 끌어다 놓거나, 이 폴더가 열려 있으면 그냥 물어봐도 됩니다.

> 질문을 바꾸면 무엇 때문에 답이 달라졌는지 알 수 없게 됩니다.

### STEP 2 · 비교 기록 (3분)

| 비교 항목 | 실습 ① — 문서 없이 | 실습 ② — 문서와 함께 |
|---|---|---|
| B-1 재택근무 | "확인할 수 없습니다" | |
| B-2 하계휴가 지원금 | "확인할 수 없습니다" | |
| 출처(조항 번호) | 없음 | |

> **바뀐 것은 AI가 아닙니다.** 같은 AI, 같은 질문입니다.
> 달라진 것은 **AI 손에 문서가 있느냐 없느냐** 하나뿐입니다.
> 이것이 RAG가 하는 일의 전부입니다.

### STEP 3 · 근거 요구하기 (3분)

> 방금 답변의 근거가 **몇 조 몇 항**인지 함께 알려줘.

조항 번호가 나오면 **PDF에서 직접 찾아 맞는지 확인**하세요.
틀린 조항을 댔다면? 그것도 기록해 두세요.

### STEP 4 · 문서에 없는 것 물어보기 ⭐ (3분)

마지막으로 이 질문을 던지세요.

```
사내 어린이집 운영 시간은 어떻게 되나요?
```

**이 내용은 문서에 없습니다.** AI가 뭐라고 답하는지 보세요.

| AI의 반응 | 의미 |
|---|---|
| "문서에 없습니다" | 우리가 원하는 동작입니다 |
| 그럴듯하게 지어냄 | **문서를 줘도 할루시네이션은 사라지지 않습니다** |

> 이것이 10번 시간에 RAG를 직접 만들 때 프롬프트에
> **"모르면 모른다고 답하라"**를 반드시 넣어야 하는 이유입니다.
